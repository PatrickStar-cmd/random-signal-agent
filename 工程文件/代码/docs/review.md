# 需求与实现情况

## 完整性结论

核心源代码、Web 资源、NumPy 依赖、环境变量模板、跨平台启动脚本、Docker/systemd 模板及 PDF 教程均存在。无需原作者的私有路径、密钥、数据集或权重即可运行本地流程。

2026-09-29 补充 Git/Docker 忽略规则、固定版本依赖、自动复现检查、运行和原理文档，修正 Python 版本说明及 systemd 虚拟环境路径，修复静态文件与上传路径越界问题。

## 功能状态

Windows 启动脚本支持匹配的外层单双引号，不再因带引号端口或日志路径失败；模型名内部空格、密钥中的 `$` 和等号保留。自动检查使用模拟 Python 入口，不调用模型或启动服务器。

静态文件及输出下载支持 URL 编码的中文、空格和加号文件名；解码后再检查目录边界，编码路径越界及空字节请求返回 404。

Welch 单边功率谱缩放已修复：合并负频率功率，直流及偶数长度 Nyquist 点不加倍；奇偶窗口纯音积分功率及 Nyquist 回归通过。

无交流谱能量的 FFT/Welch 谱熵已修复为 0，不再用均匀概率伪造接近 1 的谱熵；FFT 空谱不报告虚假谱峰。

单点信号的时域特征已修复：过零率为 0，全部统计结果可严格序列化为 JSON，不再产生空均值警告或 NaN。

预处理输入校验已实现：六种预处理方法及旧版鲁棒入口统一拒绝空数组、标量、多维数组及非有限采样值；正常输入长度和原数组保持不变。

仿真参数校验已实现：拒绝非有限数值、非正采样率/时长、不足一个样本、负噪声标准差及越界 AR 系数/脉冲概率；正常随机种子复现行为保持一致。

文件时间轴验证已实现：采样率必须为有限正数，双列时间必须递增且近似等间隔；拒绝错误时间轴，不进行隐式重采样。

文件加载拒绝单列与双列混用、时间/采样值中的 NaN 和无穷，返回具体数据错误；仍支持表头及双列后的额外数值列。

上传及麦克风接口的采样率必须为有限正数；非数值、NaN、无穷和非正值返回 HTTP 400，在文件保存或音频处理之前拒绝。

2026-09-30 边界回归：JSON 接口遇到语法错误、无效 UTF-8、非对象 JSON 或负 Content-Length 时返回 HTTP 400，避免请求线程异常退出。

## 可重复验证

环境：Windows x64、CPython 3.12.10、NumPy 2.5.3，使用新建虚拟环境安装项目依赖，`pip check` 通过。

运行 `python scripts/verify_reproduction.py`：5 组集成检查通过，包含真实本地 HTTP 请求与路径边界回归。脚本关闭外部模型，临时信号/音频使用临时目录，日志写入 `logs/verification/latest.log`。这不是所有参数组合或所有算法精度的完整证明。

`requirements.txt` 保留宽松依赖；Python 3.12 复现优先用 `requirements-repro.txt`。不同平台浮点计算可能产生微小差异。固定种子仅保证仿真随机输入，不保证外部模型回复一致。
