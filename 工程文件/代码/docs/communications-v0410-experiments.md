# v0.4.10 链路设计与课堂评阅

本模块把实际接收轨迹、工程参数、教师评阅和帧级时间表放入通信实验室的海洋风格实验面板。界面状态保存于工程文档 `v0410`，支持工程快照、导入导出和原始输入恢复。

## 本次算法步骤与测量诊断

运行含 Viterbi、LDPC、Polar 或 Turbo 译码的链路，打开「本次运行」，选择对应积木并拖动步骤滑块。输入和输出显示实际样本数与前 12 点；状态路径度量、校验结果、后验软信息、外信息随实际步骤变化。完整步骤对象可展开查看。

后端读取 `advanced.algorithm_traces` 中的 `block_id/kind/input/output/trace`，与本次积木观察点一一对应。运行状态改变时清空当前分析，候选实验与教师成果继续保留。

诊断使用本次输出观测：RMS 小于 `1e-9`、峰均比超过 `10 dB`、`|LLR| < 1` 的比例超过 `35%`，以及同步块的实际相关峰和门限等。每条记录显示积木、测量值、规则与观察建议；可以定位观察点，保留当前基线并生成单参数对照方案。噪声对照提升 `3 dB`，频偏／衰减对照使用 `0`。所有方案保留完整工程，可再次运行。

逐块耗时取执行观察器记录的 `elapsed_ms`，按耗时降序列出，并显示占比、RMS 和峰值。

## 两参数受约束选参

选择两个数值或枚举参数，输入离散候选值、配对种子和每种子帧数。约束逐行填写，例如：

```text
ber <= 0.01
papr_db <= 8
net_bit_rate >= 1000
```

两个目标各自选择最小化或最大化。系统执行完整笛卡尔积，使用相同的基础种子和帧序号。总运行量最多 `256` 帧；每个轴最多 `21` 个值。每条候选保存完整工程、所有种子和帧的实测指标、约束结果与 Pareto 标记。

BER/SER 用累计错误数与累计计数计算，其余可测数值取各次测量均值。可用指标包含 BER、PAPR、净信息速率、EVM、帧时长与运行时间；界面展示实际候选散点和结果表。Pareto 方案满足所有约束，且不存在同时在两项目标上更优或相同、至少一项严格更优的可行候选。

点击「恢复」载入候选工程；点击「同种子复跑」恢复候选与首条试验的实际种子，进行完整链路运行。完整 JSON 保留所有逐次测量，便于精确复现。

## 教师批量评阅

教师选择多份学生模式导出的作业包，或重新打开评阅包。每批最多 `64` 份，题目、初始链路、开放参数、阶段目标、权重和验收种子保持一致。

汇总显示已提交阶段、原始成绩、重验成绩、尝试次数、提示次数和教师评语。选定学生与阶段，可以载入该阶段独立工程快照。批量重验逐份读取各阶段保存的工程，按题目原始种子再次执行并验收，保留原始成绩作为对照。评语随工程和评阅包保存，支持 CSV 成绩单与完整 JSON 评阅包导出。

## 帧级场景时间表

总帧数为 `1–128`，每个事件设置帧号、信道数值参数、目标值与变化方式。可调参数包括信噪比、频偏、干扰幅度、衰减等。

- `step`：从事件帧开始使用目标值。
- `linear`：从同参数前一事件值线性过渡，在当前事件帧到达目标值；首段从第 `0` 帧的工程初值开始。
- 时间表帧号从 `1` 开始；每帧的种子为 `初始 seed + 帧号 - 1`，在合法种子范围循环。
- 所有帧使用同一运行状态字典，信道振荡器、接收环路与滤波状态跨帧连续保留。

设置恢复指标、阈值与连续达标帧数。每个事件帧至下一事件之前构成观察窗口；连续达标后记录恢复起始帧、距离事件的帧数与确认帧。图中显示逐帧实测值与事件标记，表格保留逐帧参数、种子、状态组数和恢复结果。运行记录可导出为 JSON。

观察器 `experience.frame` 沿用已有的从 `0` 开始的执行合同；场景表 `rows.frame` 使用从 `1` 开始的教学帧号。

## 后台接口与报告

同步接口：

- `v0410-inspect`：`{program, result}` → `inspect_run(program, result)`。
- `v0410-classroom`：`{submissions}` → `classroom_import(submissions)`。

后台任务复用现有进度和取消入口：

- `pareto`：`optimize(program, settings, progress, cancel)`。
- `classroom-recheck`：`recheck(submissions, settings, progress, cancel)`。
- `scenario`：`scenario(program, settings, progress, cancel, observer_callback)`；回调接收每帧真实 `Observer`，供观察窗口使用。

统一报告素材包含诊断、逐块耗时、真实译码轨迹、Pareto 实测点、场景事件与恢复帧数、教师评阅、多路汇合对照，以及 MLSE 路径、MUSIC 空间谱、TDL 时延功率及时间演化、自描述帧接收、ISAC 距离速度图。ISAC 横纵坐标使用接收结果提供的实际距离和径向速度。
