# 🧩 v0.4.12 积木编程最终完善版

本版把通信实验室收拢为 Scratch 式积木拼接、完整工程实验、运行调试、课程记录和成果交付。海蓝、薰衣草紫、加粗边框及已有算法继续沿用，界面展示间隔符统一使用空格。

目录保留 **231 个可添加信号积木、固定信宿、122 个预设**，增加 **4 类实验工具积木与 12 个完整课程**。双输入汇合与二维 CA-CFAR 继续参与图工程。

## 🧭 从搭建到交付

1. 在积木工坊搜索模块，将积木拖到拼接位置；常用参数直接在积木内编辑，完整参数显示在侧栏。勾选积木后可以复制、剪切、粘贴、封装与展开组合，也可以添加注释。
2. 线性链路按运行顺序拼接。分支工程使用“并行接收”容器组织共享前段、各路接收、双输入汇合与公共尾段；折叠、缩放和注释随工程保存。
3. 点击 **🔨 Build** 检查工程，按诊断定位对应积木。点击 **▶️ Run** 或逐步运行，查看当前执行块、观察点、执行与复用区段。接收分支局部重跑继续复用实际共享输入。
4. 添加“观察探针”“参考对照”“指标汇总”“验收条件”，选择真实观察点与指标。参考对照可分别设置起点和样本数，计算 MSE、BER、SER 或 EVM。
5. 在“完整工程实验”选择多种子批量、参数扫描、约束选参或课程验收。参数带有共享区段、分支或汇合路径，任务保存各次实际种子、指标、工具结果、输入摘要和执行记录。
6. 在“课程与实验记录”载入课程，填写预测、观察、结论和挑战记录。课程验收执行种子 **42、1042、2042**，显示每次实测指标及验收结果。
7. 保存命名记录、设为基线，对照参数、连接和结果差异。选择“恢复并复跑”可恢复完整图、接线和记录实际种子；保留最近 8 份命名记录。
8. 编排报告素材及顺序、填写图注与结论，浏览器直接展示最终 PDF。导出成果 ZIP 后，可以校验导入工程，或运行其中的 Python 复现脚本。

## 🔬 实验工具与执行范围

| 工具 | 实际数据与输出 |
| --- | --- |
| 🔎 观察探针 | 从选定积木的真实输出数组截取窗口，保留起点、点数和样本。 |
| 📏 参考对照 | 对齐参考与观察窗口，计算 MSE、BER、SER 或 EVM。 |
| 📊 指标汇总 | 汇总主结果、指定接收分支、汇合及 CFAR 的实际指标。 |
| ✅ 验收条件 | 比较实测指标与阈值，保存实际值、比较符、通过状态和样本量。 |

完整工程入口使用 `document_schema=2`。图结构保存在 `graph`，实验工具保存在 `tools`。参数路径包含 `shared/积木ID`、`rx1/积木ID`、`rx2/积木ID`、`tail/积木ID` 等执行区段；指标使用 `merged.ber`、`rx1.ber`、`cfar1.detections` 等名称，`ber` 对应主结果。

完整工程任务运行整张图，并保存分支与汇合统计。连续帧和协议物理层提供明确的接收路径选择，按所选路径执行原有物理链路功能。

数值配置与布局分开管理。积木参数、顺序、接线和工具配置参与工程检查；注释、缩放和折叠保留显示状态。运行结果使用工程令牌、信号令牌与输入 SHA-256 关联实际执行。

## 📚 12 个完整课程

每份课程包含学习目标、初始工程、运行前预测、操作步骤、观察内容、结论问题、挑战及可运行验收条件。

| 课程 | 初始工程与重点 |
| --- | --- |
| 模拟调制与恢复 | AM 包络恢复，扩展比较 FM 与噪声。 |
| 数字调制与星座 | QPSK、星座散布、比特误码与信噪比。 |
| 编码与软判决译码 | 卷积码、软 Viterbi、LLR 与译码路径。 |
| 载波与符号同步 | 复基带接收、频偏、相位和符号定时。 |
| 多径与自适应均衡 | NLMS、抽头、步长与 DFE 对照。 |
| OFDM 与频率选择性信道 | 循环前缀、导频跟踪、频域均衡。 |
| 射频非线性与数字预失真 | 记忆功放、回环训练与 DPD。 |
| 多天线与空间接收 | MMSE-SIC、信道矩阵、检测顺序及残差。 |
| 重传与自适应传输 | 文件分包与 CRC，关联 ARQ、HARQ、AMC 面板。 |
| 录波回放与业务恢复 | I/Q 接收、SigMF 导出导入及成果包复跑。 |
| 共享输入与分支汇合 | 相同信道观测上的 NLMS / DFE 与局部重跑。 |
| 多目标通感与 CFAR | 距离速度功率、门限、局部噪声及检测峰。 |

专项测试覆盖真实图执行、分支指标、工具窗口、约束与队列、调试控制、接口保存、12 课程三种子运行、命名记录恢复、报告素材排序、成果校验和独立目录 Python 复跑。浏览器脚本验收覆盖生产模块的拼接编辑、课程记录和最终 PDF 预览。

接口统一使用 `/api/communications/{action}`：

| 动作 | 用途 |
| --- | --- |
| `workbench-build`、`workbench-diagnose` | 完整工程检查、参数目录与定位诊断。 |
| `workbench-run`、`workbench-debug`、`workbench-task` | 完整工程运行、调试及多条件任务。 |
| `delivery-courses`、`delivery-course` | 课程目录和完整初始工程。 |
| `delivery-record`、`delivery-restore`、`delivery-diff` | 命名记录、完整恢复及参数、连接、指标差异。 |
| `delivery-export`、`delivery-import` | 带清单校验的成果 ZIP 导出与导入。 |
| `report-preview`、`report-pdf` | 报告素材列表和最终 PDF。 |

任务先使用 `workbench-build` 取得令牌，再按既有作业机制提交和轮询结果。数值与前端日志位于 `logs/communications-v0412/`，发布校验日志位于 `logs/release/`；页面与 PDF 验收材料位于 `debug/v0412/` 及 `debug/v0412-delivery/`。
