## 🧱 六组算法与新增积木

| 算法组 | 积木或入口 | 实际处理 |
| --- | --- | --- |
| 🧵 MLSE | 公共训练帧、MLSE 序列均衡（2 块） | 公开训练估计复 FIR；按完整序列最小欧氏距离进行 Viterbi 检测 |
| 📐 MUSIC | 到达角估计、MUSIC 引导 MVDR（2 块） | 从接收协方差分解子空间、扫描角谱，按公开导频选目标并形成自适应波束 |
| 🌊 标准信道 | TDL-A / B / C（1 块） | 3GPP 功率时延谱、可缩放时延扩展、Jakes 衰落和跨帧连续状态 |
| 📦 连续物理帧 | 自描述组帧、连续流信道、捕获重组（3 块） | BPSK 卷积保护帧头传输长度、MCS、序号与业务偏移；支持分块录波和截断重捕获 |
| 🌀 Turbo | RSC 并行级联编码、BCJR 迭代译码（2 块） | Log-MAP / Max-log-MAP 交换外信息；公开交织、终止尾位与逐轮轨迹 |
| 🔁 IR-HARQ | 协议与速率控制器 | 卷积母码 RV 速率匹配、实际 LLR 缓冲与 CRC 反馈；同预算比较 Chase |

此外新增 3 个通感积木：OFDM 通感组帧、单目标延迟与多普勒、OFDM 通信与测距测速。

MLSE 支持 BPSK/QPSK、2/3 个信道抽头。MUSIC 支持前后向平均与空间平滑，通过公开导频选择目标。TDL-A/B/C 使用完整标准功率时延谱，配置 RMS 时延扩展和最大多普勒；信道保留分数延迟滤波和衰落状态。详见[接收与标准信道](communications-v0410-receiver.md)。

自描述帧的接收配置只需捕获阈值；载荷长度、MCS 和重组偏移均来自实际保护帧头。支持 BPSK/QPSK 及各自的卷积编码载荷，逐包切换 MCS。SigMF / 原始 I/Q 可选择自描述格式，自动接入连续帧接收链路；接收结果显示成功包、CRC、覆盖区间和恢复字节。

Turbo 信息块长度可选 32–512，迭代 1–12 轮；两个 8 状态 RSC 编码器各自终止，接收图表显示真实先验、外信息和后验。IR-HARQ 在参考链路及当前卷积编码、PSK/QAM 软接收链路上执行，保留实际 OFDM/信道等处理；每轮名义码率 2/3 或 3/4。对照实验使用相同分包、预算和配对种子，统计实际样本、能量、重传与吞吐。详见[物理帧、Turbo 与 IR-HARQ](communications-v0410-framing.md)。

## 🔬 五项实验功能

1. **本次算法回放**：按积木 ID 记录实际输入、输出和内部步骤，查看 Viterbi、LDPC、Polar、Turbo 等算法的路径与软信息。
2. **测量诊断与性能观察**：把 RMS、峰均比、LLR 可靠度和同步观测连接到具体积木；定位观察点、保存基线并生成单参数对照，查看逐块耗时。
3. **受约束 Pareto 选参**：组合两个参数的离散值，使用相同种子和帧数测量；按 BER、PAPR、净速率、EVM、时长等约束筛选方案，恢复候选并同种子复跑。
4. **教师批量评阅**：导入同题学生作业，查看独立阶段快照、原始成绩、尝试和提示记录；按题目种子重新验收，保存评语并导出成绩 CSV / 评阅包。
5. **帧级场景**：设置信道参数的 step / linear 时间表，跨帧保留信道和接收状态；以连续达标条件统计恢复起始帧、恢复时间与确认帧。

任务复用后台进度与取消入口，结果随工程保存。详细参数、统计方法和接口见[链路设计与课堂评阅](communications-v0410-experiments.md)。

## 🔱 两路接收汇合与单目标通感

先建立两条共享发送与信道部分的接收分支，在“接收汇合与 OFDM 通感”选择第二条分支。汇合点可选解调前的复符号或软解调后的 LLR，使用两路加权相加或选择一路；输入类型、点数、采样率及汇合后的链路保持一致。结果保存两个独立分支、汇合后的实际译码结果和共享样本摘要。

通感预设使用 QPSK OFDM。信道叠加直达路径和单目标往返回波，距离对应分数延迟、径向速度对应多普勒。通信端通过公开训练估计频域信道；本机雷达使用本地发射网格作为参考，对实测回波进行延迟和慢时间处理，形成距离—速度谱。结果展示检测峰、距离/速度分辨率、通信 BER 与原始二维谱。
