## 运行与参数

重启 Python 服务并刷新通信实验室，在“实验示例”选择“线性 · AM / DSB-SC / SSB / VSB”或“非线性 · FM / PM / 窄带 FM”，Build 后 Run。直接模拟链路为：

```text
正弦/方波/高斯模拟信源 → 模拟调制器 → 信道 → 同制式模拟解调器 → 信宿
```

无需 PCM。模拟信源也可以按旧方式通过 PCM、数字调制和译码传输。禁止把比特送入模拟调制器，或把模拟复包络送入数字解调器。

| 参数 | 范围及默认 | 含义 |
| --- | --- | --- |
| 所有模拟调制器 `amplitude` | 0.1–8，默认 1 | 载波/发送复包络幅值尺度 A。 |
| AM `sensitivity` | 0.01–16，默认 1 | 调幅灵敏度 ka，单位 1/信源单位；`1+ka·m` 变负时包络翻转。 |
| FM `sensitivity` | 0.01–24000，默认 16 | 频偏常数 kf，Hz/信源单位。窄带示例为 1。 |
| PM `sensitivity` | 0.01–16，默认 1 | 相偏常数 kp，rad/信源单位。 |
| SSB/VSB `upper` | 布尔，默认 true | 保留上边带；关闭保留下边带。 |
| SSB `method` | 0 / 1，默认 0 | 0 为 Hilbert 相移法，1 为理想边带滤波法。 |
| VSB `vestige_hz` | 0.01–24000，默认 4 | 载频两侧互补过渡的半宽；必须小于采样率的一半。 |
| AM 解调 `method` | 0 / 1，默认 0 | 0 为包络检波，1 为相干解调。 |
| 模拟解调 `compensate` | 布尔，默认 true | 使用配置中的已知复增益补偿衰减和相位。 |
| 模拟解调 `cutoff_hz` | 0–24000，默认 0 | 理想低通截止 Hz；0 不滤波，非零须低于采样率的一半。 |
| `analog_awgn.snr_db` | −10–60，默认 20 | 按发送端实测复包络平均功率定义的采样 SNR，不是数字 Es/N0。 |

理想、衰减、相位旋转和丢失信道可用于两类链路。数字 AWGN 与模拟 AWGN 分开选择，Build 拒绝混用。模拟信道里的“丢失”按样本发生。

## 模型与解调原理

设真实带通信号 `s(t)=Re{u(t)·exp(j2πfc t)}`，程序处理其复包络 `u=I+jQ`。横轴频率是相对载频的偏移，0 Hz 表示载频位置；没有生成射频载波。直接模拟链路所有样本以工程 `sample_rate=fs` 为时钟，`symbol_rate` 只影响数字链路。使用 NumPy，无新增运行依赖。

- AM：`u=A(1+ka·m)`。包络检波计算 `(|u|/A−1)/ka`；相干解调计算 `(Re(u)/A−1)/ka`。过调制下前者失真，后者在理想同步时仍能还原。
- DSB-SC：`u=A·m`，相干解调取 `Re(u)/A`。负信源会产生 π 相位翻转。
- SSB：上边带 `u=A/2·(m+j·Hilbert(m))`，下边带取共轭。FFT 实现 Hilbert 时保留 DC/Nyquist、正频率加倍、负频率置零。滤波法保留指定一侧、DC/Nyquist 取半，两种方法等价。相干解调取 `2Re(u)/A`。
- VSB：`u=A·IFFT(FFT(m)·H(f))`；上边带 `H(f)=1/2+1/2·clip(f/fv,−1,1)`，下边带反转频率。`fv` 是 `vestige_hz`，DC/Nyquist 强制取半，满足 `H(f)+H(−f)=1`，对应课件第 63 页无失真条件。解调取 `2Re(u)/A`。
- FM：`θ[n]=(2πkf/fs)·Σ(i=0..n)m[i]`，`u=A·exp(jθ)`；展开接收相位后差分，再乘 `fs/(2πkf)`，对应鉴频。
- PM：`θ[n]=kp·m[n]`，`u=A·exp(jθ)`；展开相位并扣除初始参考相位，再除 kp。

FM/PM 在数据前插入一个已知零相位参考样本。FM 差分后与原始消息长度一致，PM 用它恢复非零的首个信源样本；接收器不读取干净信源来还原相位。它是理想训练参考，不是载波恢复算法。Build 检查包括参考到首样本在内的相邻相位增量严格小于 π；超限应提高采样率或减小信源幅值/灵敏度。接收幅值接近零时显示相位不可靠警告，噪声或丢失仍可导致周跳。

FFT 边带滤波和解调低通采用有限帧周期边界，因此非整周期信号存在边界效应。低通会主动删除信源截止频率外的成分，不能把这种误差算成传输噪声。高调制指数可能产生超出 Nyquist 的高阶边带；相邻相位校验保证展开条件，不等同于所有频谱成分都不混叠。已知增益补偿不估计真实信道；未实现载波频偏、PLL、硬件鉴频器、多径及实时流。

模拟白噪声的复方差为 `Ptx·10^(−SNRdB/10)`，I/Q 各占一半；Ptx 为完整发送帧（包含角调制参考样本）的平均功率。噪声始终参考发送端，前置衰减会降低接收 SNR。它是离散复包络采样 SNR，不能直接套用课件连续带通噪声谱密度或数字 Eb/N0 公式。

## 显示与保存

直接模拟链路显示全帧 RMSE、还原样本数、输出信误比 `10log10(Σm²/Σ误差²)` 及补偿后复包络归一化误差。输出信误比包含失真；近零误差显示“无误差”，有误差的零信源显示“—”，JSON 使用 null，不会输出 Infinity。详细指标另有最大绝对误差、发送功率、参考样本数与 AM 过调制样本数。没有虚构 BER、码率或星座点。

接收窗口保留完整源/输出和滑动浏览。分析页提供已调 I/Q、信道 I/Q 和完整发送帧的双边复包络周期图，频谱单位为相对载频 Hz 与 dB/Hz（单位幅值参考）；未做单边加倍。CSV 导出全部 N 个还原样本及参考。结果 JSON 的 `transport='analog'`，`analog` 含制式、家族、警告、参考样本数、发送 I/Q 前缀和全帧频谱；`sink` 含完整数组。旧数字结果结构、schema 1 和三种旧示例保持一致。

## 验证

课堂对照实验：AM 把信源幅值从 0.7 改成 2，比较包络/相干检波；SSB 切换上下边带并观察频谱反转；VSB 在 8 Hz 正弦前叠加一个 2 Hz、幅值 0.25 的正弦，默认 4 Hz 残留宽度会保留低频的部分反侧边带，而 8 Hz 分量只有主侧边带。窄带 FM 的小频偏会放大差分鉴频噪声，可把 SNR 提高到 40 dB 并设置 16 Hz 解调低通观察还原，再逐步加噪声；未滤波的高 RMSE 也属于实际模型结果。

`python scripts/test_communications.py` 共 24 项：原 14 项，加六制式无噪声还原、SSB 两种方法和两侧频谱、VSB 互补条件及奇偶长度 DC/Nyquist、AM 过调制/相干恢复、FM 频偏与 PM 相偏、非零首样本、窄/宽调制指数的贝塞尔谱线、低通、噪声标定/衰减、非法链路/采样条件、零信源/全丢失。API 遍历全部十个示例。参考贝塞尔函数来自已有测试依赖 SciPy，运行服务只用 NumPy。
