# v0.4.9 实验编排与教学过程

## 持久化任务与续跑

“工程与调试控制 → 断点与实验续跑”保存一维扫描、二维扫描、批量工程和目标 SNR 搜索的任务入口。运行后可停止，随后选择任务继续；页面刷新后可重新连接运行中的任务，服务重启后从本地检查点继续。

- 批量实验以工程、基础种子和帧序号标识一次测量，检查点保存完整结果行。
- 二维扫描保存每一行的一维扫描检查点，保留各网格点已经累计的帧与误码计数。
- 目标搜索保存完成的 SNR 点和当前 SNR 点的部分种子测量。
- 每次测量完成后将检查点写入 `communication-jobs/<session-hash>/`，通过临时文件替换保存。每个浏览器会话保留最近 30 个检查点，工程界面保留最近 20 个任务入口。
- 续跑使用检查点中的工程和设置，完成后更新原实验视图。

## 真实输出断点

选择积木和条件后点击“添加断点”，再点击“运行至断点”。支持到达积木、输出 RMS、输出峰值、平均绝对 LLR，以及低可靠度比例（`|LLR| < 1`）。LLR 条件来自软解调积木的完整输出数组。

命中后，界面显示触发积木和实际值，并选中对应积木；“下一积木”执行下一步，“继续”运行至后续命中点。原逐积木调试与暂停功能继续可用。

## 统计与记录复跑

批量结果增加四类统计视图：

1. BER 累计值和 95% Wilson 区间。
2. 有效吞吐或净比特率的箱形图与实际测量点。
3. 协议交付时延或物理链路帧时长的分布。
4. 以首个工程为基线、按基础种子和帧序号配对的 BER 差值。

逐次记录提供“复跑记录”：恢复该行工程及实际种子，使用原运行模式和协议设置重新运行。物理链路结果进入现有信号观察器，协议结果进入闭环协议结果视图。统计结果保留原记录。

## 学生实验与阶段成果

先在任务编辑器准备初始链路、开放参数与阶段目标，再进入“学生实验”。界面提供开放参数编辑，固定参数保持锁定。点击“提交当前阶段”使用任务指定的种子重新运行，仅验收当前阶段；每次尝试均保存工程、测量、时间、笔记和提示使用数。

阶段通过后保存独立成果快照，并进入下一阶段。后续调参保留早期阶段成果。历史列表可重新载入任意尝试或通过快照；“查看阶段提示”记录使用阶段和时间。作业包支持 JSON 导出、校验导入和继续实验。

切换教学任务或导入其他作业时，当前作业加入“已保留作业”。可在列表中打开原作业继续，单个工程保存最多 20 份历史作业。

作业包字段：`submission_schema`、`task`、`student`、`notes`、`program`、`active_stage`、`stages`、`attempts`、`hint_events`。`stages` 按任务顺序保存通过记录；每条 `attempt` 包含 `stage/number/time/program/changes/trials/passed/notes/hints_used`。

任务编辑草稿、实验参数和学生开放参数输入随工程保存。输入中的草稿值在刷新或恢复工程时继续显示，提交时执行数值与目标格式校验。

## 接口与验证

- `job-control`: `control=resume` 继续持久化实验；原 `resume-sweep` 保留。
- `job-start`: `debug` 支持 `breakpoints` 和 `debug_mode=continue`；新增 `classroom-stage`、`batch-replay`。
- `classroom-submission-validate`: 接收 `{submission: ...}`，返回规范作业包。
- 核心验证：`.venv/Scripts/python.exe scripts/test_communications_v049_experiments.py`。
- 界面验证：`node scripts/test_communications_v049_ui.js`。

核心测试覆盖服务重启续跑、部分 SNR 点和二维网格恢复、条件断点、精确种子复跑、独立阶段历史与作业包往返；界面测试覆盖输入保存、统计视图、繁忙状态下复跑提交、续跑结果路由及学生成果保留。
