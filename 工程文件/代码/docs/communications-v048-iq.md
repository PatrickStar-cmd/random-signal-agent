# v0.4.8 I/Q 录波与接收回放

在「闭环链路与空间通信 → I/Q 录波」中导入 `.sigmf` 包，或同时选择一组 `.sigmf-data` 与 `.sigmf-meta`。原始数据支持 `cf32_le`、`cf64_le` 和 `ci16_le`，分别表示小端复数 float32、复数 float64 和交错 I/Q int16。int16 按 32768 归一化，内部录波保存为复数 float32。

录波信源保存完整复采样，容量为 262144 点。实际回放采样率使用信源参数 `rate_hz`，范围 16 Hz–1 GHz；时间轴、频率估计和频谱测量都使用录波采样率。中心频率通过 SigMF capture 信息保存。

## 接收格式

- **符号采样**：载入匹配调制的解调器，可增加 AGC、载波同步、帧同步、均衡及噪声估计。
- **RRC 波形**：配置每符号采样、滚降和脉冲跨度，执行匹配滤波及 Gardner 定时恢复。导出已匹配的观察点时，元数据记录处理状态，导入后从符号同步继续。
- **OFDM 波形**：配置 FFT、循环前缀、有效子载波及导频间隔，利用公共训练符号估计信道并恢复数据子载波。
- **公共帧头**：通过接收相关峰定位帧起点。公共前导保留到均衡及噪声估计完成，解调时剥离前导并输出业务比特。

接收信宿展示实际恢复比特、录波点数、接收功率和 PAPR。误码率、符号错误率和参考 EVM 使用空值；回放只读取录波与公开接收格式。

## 完整采样导出

先运行工程，再选择复符号、复波形或 OFDM 观察点，导出包含全部采样的 SigMF TAR 包。数据使用 `cf32_le`；元数据记录采样率、中心频率、SHA-512 校验值及接收格式。

`randomsign:receiver` 扩展包含调制、脉冲或 OFDM 参数，另保存以下公开帧格式字段：

| 字段 | 含义 |
|---|---|
| `payload_symbols` | 有效符号数，0 表示使用全部可恢复符号；用于去除 OFDM 补齐及 RRC 尾部保护采样 |
| `sample_offset` | 录波中首符号脉冲中心的位置，由公开发送保护段和滤波群时延确定 |
| `framed` | 录波包含公共前导 |
| `preamble_length` | 公共前导符号数，范围 16–1024 |
| `matched` | 导出的观察点已经完成匹配滤波 |

有效符号数包含待处理的公共前导。数据包保存采样和格式元数据，接收机依据这些公开参数处理录波。导入时检查 SHA-512；导出参数取自所选观察点之前的实际处理链。
