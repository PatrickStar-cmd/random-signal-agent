# 🪸 v0.4.11 可视接线与分支实验

本版把共享发送与信道、2–4 条接收分支、双输入汇合、公共译码尾段及分析端口保存为一个可视工程。海洋配色、加粗边框、原参数面板、原线性工程和既有实验功能继续沿用。

目录包含 **231 个可添加积木、固定信宿及 122 个线性预设**；可视编辑器另提供 **双输入汇合、二维 CA-CFAR 分析节点** 和 **NLMS / DFE、多目标通感**两个完整实验入口。

## 🧭 推荐操作

1. 在通信实验室展开“🪸 可视接线与分支实验”，载入“NLMS / DFE 示例”。共享前段包含随机比特、卷积编码、QPSK、公共前导、复多径和 AWGN；两路分别使用线性 NLMS 与 DFE，再经软 QPSK 输出 LLR。
2. 点击积木标题，在原参数面板编辑；拖动标题保存位置。点击输出与输入端口完成接线，也可使用起点、终点和端口下拉框。选择连接后可断开、重连，普通节点可删除；工具栏撤销与重做涵盖这些编辑。
3. 点击“Build 接线”，检查端口类型、点数、速率和完整拓扑。选择汇合 A / B 输入、选择一路或两个权重，公共尾段执行真实软 Viterbi 译码。
4. 点击“完整运行”：共享信源、发送处理和信道各执行一次。修改其中一条接收分支后点击“局部重跑”，复用冻结输入及未改动分支。执行表分别显示实际执行和复用数量，保存输入 SHA-256、工程版本和分支身份。
5. 点击“多目标 CFAR 示例”，观察正、负径向速度的目标。通感接收器主端口继续输出通信符号，功率端口连接 CFAR。调节训练、保护、直达排除、聚类及 Pfa 参数，查看功率、门限、噪声热图和检测清单。
6. 保存快照或导出完整工程 JSON；刷新、重新打开工程后继续编辑。Python 导出使用安装目录中的相同引擎复现整张图；PDF 包含拓扑、各分支参数、汇合设置、输入摘要和检测结果。

## 🧱 工程与执行原理

`document_schema=2` 增加 `graph.schema=1`。图文档以 `prefix`、`branches`、`merge`、`tail`、`analyses`、`edges` 为唯一结构来源，`layout` 单独保存坐标。普通线性程序由当前接收分支投影产生，因此前段与公共尾段修改会同步到各分支。旧 schema-1 链路、schema-2 工程、组合积木和子工程仍按既有入口打开；“转为可视工程”把相同前段与相同公共尾段收拢到图结构。

本版分段执行面向固定随机种子的单帧数字复基带链路。冻结点在共享信道之后；快照保存实际样本、信源参考、编码栈、码字长度、调制格式、公共训练、采样率、随机数状态和滤波状态。每条接收分支获得独立快照副本。前段或全局参数变动重新生成快照；接收分支参数变动只执行该分支和后续译码。布局移动保持数值构建令牌及结果有效。

汇合端口使用相同帧、符号顺序、编码位顺序、制式和速率。复符号按各接收器的前导剥离与增益设置对齐；LLR 符号约定为 `log(P0/P1)`。选择一路和单位权重完整保留该接收器状态与有效噪声方差；一般符号加权使用合并星座残差估计有效噪声。共享信道输入的两路输出具有相关性，加权效果由实际 BER / EVM 对照评价。

后台每个浏览器会话保留一个冻结工程，最多保留四个会话；单个工程冻结数组预算为 128 MiB。工程 JSON 保存配置与结果，服务内快照随进程生命周期管理。恢复工程后的首次运行自动建立当前输入快照。

## 🛰️ 多目标回波与二维 CA-CFAR

新增 `isac_echo_multi` 接收 0–8 个目标组成的 JSON 表。每个目标包含 `range_m`、`velocity_mps`、`amplitude`、可选 `phase_deg`；载频与直达幅度在信道上统一设置。距离对应往返分数延迟，径向速度对应多普勒，各目标相位独立延续。空目标表配合零直达幅度和 AWGN 用于纯噪声实验。

接收器计算本机发射网格与接收网格的比值，经距离 IFFT 和慢时间 Hann 窗 FFT 得到线性功率 `power`，并输出距离、速度坐标轴。绘图时转换到 dB；CFAR 在原始线性功率上计算。

对于每个完整窗口内的检测单元，排除保护窗和直达列，以剩余 N 个训练单元的平均功率估计噪声。门限为：

`threshold = mean(training_power) × N × (Pfa^(-1/N) − 1)`

边界单元仅在完整训练窗落入网格时参与检测；门限和噪声网格的其他位置保存为 `null`。超过门限的相邻单元按配置半径聚类，每个连通簇保留实测功率最高的峰。检测清单包含距离、速度、功率、门限、噪声和簇内单元数。

CA-CFAR 自动门限的独立平方律噪声假设及完整训练区域规则参考 [MathWorks 二维 CFAR 文档](https://www.mathworks.com/help/phased/ref/phased.cfardetector2d-system-object.html)。Hann 窗 OFDM 的统计同时保留实测结果：

| 验收输入 | 有效检测单元 | 超门限单元 | 实测比例 | 设置 Pfa |
| --- | ---: | ---: | ---: | ---: |
| 独立平方律噪声，种子 411，32 个 128×128 网格 | 460672 | 474 | 0.00102893 | 0.001 |
| 纯噪声 OFDM，种子 0–15，Hann 慢时间窗 | 49088 | 46 | 0.000937093 | 0.001 |

默认双目标实验设置 780 m / 37.5 m/s 与 1560 m / −56.25 m/s，主要实测峰为 780.71 m / 39.04 m/s 和 1561.42 m / −54.65 m/s；结果保留有限网格分辨率和全部超过门限的峰。
