## 自动符号同步

接收器已知帧的粗起点、名义码元率 Rs、sps 和滤波延迟；算法从**接收滤波输出**估计小数符号相位与持续漂移，不读取信道延时/ppm 或发送数据。它不负责未知整符号帧定位、消息边界检测或射频载波同步。

非线性提取先略去帧边缘，在最多约 128T 的窗口内去均值后平方，提取 Rs 处的复谐波 `C=Σv[n]exp(−j2π(n−delay)/sps)`。相位为 `−arg(C)/(2π)`，折回 ±.5T。矩形脉冲直接接收改用差分整流，再把跳变相位移半周期到码元中心。这是课件“非线性产生时钟分量、窄带选取”的有限窗口实现。谱线比值小于 .005 或常值窗口保留手动起点；“时钟分量已提取”是启发式可用性提示，并非锁定证明。开环方式不跟踪长帧频率漂移。

早迟门使用课件绝对值支路，误差 `e=(|r(t+Δ)|−|r(t−Δ)|)/RMS`；后侧幅值较大就推迟采样，前侧较大就提前。Gardner 使用相邻两中心的中点：`e=r(mid)·(r(previous)−r(current))/RMS²`，不需要发送符号或判决。两者均先尝试上述初相提取，再每码元更新 PI：`ν←ν+Ki·e`、`τ←τ+ν+Kp·e`，在 `delay+(k+τ)·sps` 处线性插值。阻尼取 1/√2，由归一化带宽计算 Kp、Ki。ν 限于 ±.002T/码元，误差限幅 ±2，累计偏移超过 64T 报错。

Gardner 的非数据辅助结构及带宽/插值环路参考 [MathWorks Symbol Synchronizer](https://www.mathworks.com/help/comm/ref/symbolsynchronizer.html)。早迟门采用本课件的绝对值差，区别于该页面列出的另一种乘积检测器。过小滚降、带宽过窄、长连续常值、强 ISI 或低 SNR 都可能削弱时钟分量或改变锁定点；当前没有统一的盲锁定判据或全捕获范围保证。

## 判决反馈与自适应算法

令前向观测向量为 `x[k]=(r[k+N],…,r[k−N])`，过去判决为 `q[k−1],…,q[k−L]`。DFE 输出为 `y[k]=fᵀx[k]−bᵀqpast`，再取最近合法线路/PAM 电平作为判决。它用过去判决估计并减去后游串扰；判错也可能通过反馈继续传播。前向抽头含 N 码元前瞻，相当于有限帧缓冲中保留 N 码元处理延迟，不代表实时电路实现。

固定 DFE 显式使用配置的脉冲、线性信道和接收滤波响应 h。先在中心组合增益为 1 的约束下，最小化有限范围的前游及未被反馈覆盖的残余响应能量，加 λ‖f‖² 正则；再将组合响应的第 1…L 个后游值设为 b。它不是通过训练估计出的未知信道均衡器。范围以外的残余 ISI、非线性丢失和噪声仍可能存在。

自适应线性均衡只有 f，自适应 DFE 同时更新 f、b。合并输入 `u=(x,−qpast)` 与权重 `w=(f,b)`，先算 `y=wᵀu`，训练段期望 d 是公共前导，数据段 d 是本接收器的最近电平判决，误差 `e=d−y`：

- LMS：`w←w+μeu`。
- NLMS：`w←w+μeu/(10⁻⁸+uᵀu)`，用输入能量归一化步长。
- RLS：初始化 `P=I/δ`，`K=Pu/(ρ+uᵀPu)`，`w←w+Ke`，`P←(P−KuᵀP)/ρ`；每步对 P 对称化。非正分母、非有限系数或绝对权重超过 10⁶ 会明确报错。

训练期间反馈寄存器装入公共训练值，之后只装入自己的硬判决；关闭“训练后按判决继续自适应”会冻结权重，但 DFE 仍执行判决反馈。默认中心前向权重为 1，其余为 0。自适应流程不接受配置的信道响应，也不读取真实数据比特。结构和训练/判决切换参考 [Adaptive Equalizers](https://www.mathworks.com/help/comm/ug/adaptive-equalizers.html)，联合 LMS/RLS 权重更新参考 [Decision Feedback Equalizer](https://www.mathworks.com/help/comm/ref/comm.decisionfeedbackequalizer-system-object.html)。这些是有限阶实值符号间隔实验；收敛依赖步长、训练激励、信道可辨识性和噪声，不能保证任意信道恢复。

## 公共前导、指标和兼容性

发送器在线路编码/PAM 映射完成后，将固定公开种子 20261012 产生的合法电平码元加到数据之前。前导独立于消息和实验随机种子，实际通过脉冲、信道、噪声与接收器。它是额外帧字段，不经过线路编码状态机；接收器在 PAM 解映射/线路译码前删掉它，数据段编码初态不改变。前导不是额外的干净接收观测。

BER 和电平 RMSE 只计算数据段；仿真参考用于结果统计，不用于自动同步或自适应更新。发送噪声参考功率包含实际发送前导，详情 `payload_efficiency=payload_symbols/frame_symbols` 单独显示训练开销。原“有效码率”仍为源比特/编码后比特，没有计入前导开销。

时钟图显示 τ[k]/T，末段抖动为最后至多 128 点去线性趋势后的标准差。收敛图显示最近 32 次接收误差的 MSE（dB），最多 256 个展示点；训练结束后为判决引导误差，可能在错误判决时很小，不能当作真实误码率。训练初末 MSE 分别取前/后至多 64 个训练符号。眼图仍取数据段的名义接收位置，在自动定时/均衡前观察。

新字段默认关闭或 0；工程 schema 1 不变，规范化时省略新字段的默认值，保证原 22 个示例的完整工程、Build token 和结果逐字段不变。表单对缺省字段显示 catalog 默认值，显式未填写的 null 仍保留。新增结果位于 `baseband.recovery`，关闭这些功能时旧结果结构不增加字段。
