# v0.4.6 界面布局与交互优化

## 工作区

保留海洋渐变、鲸鱼、表情分类与粗边框。桌面按积木库、链路、参数三栏排布，参数与信宿观察在右栏切换；链路拥有独立滚动区域。组合积木与接收分支位于链路底部。批量选择开启后可勾选相邻积木，仍支持框选、拖动和上下移动。

工具栏常驻工程名称、保存快照、实验库、撤销/重做、Build 与 Run。工程菜单提供打开版本、复制、导入、清空、完整工程 JSON、链路配置 JSON 和 PDF 报告。调试菜单集中单步、继续、暂停、停止、扫描续跑及连续多帧；参数菜单提供种子和采样/符号时钟。

## 实验库与分析

实验库保留 64 个示例，可按名称、算法及主题搜索。主题筛选中的“任务对照（7）”可直接载入对应链路并进入性能对照。取消示例替换会保留原链路；替换后可撤销。

分析面板包括结果总览、信号观察、射频测量、性能对照四个标签页，支持收起及大图模式。箭头键、Home/End 可切换分析标签；Esc 退出大图或关闭弹窗。导出实验数据菜单位于结果总览，包含信宿 CSV、结果 JSON、射频测量 JSON 和扫描 JSON/CSV。

任务对照显示所属任务、完成时间、种子、符号率、积木数与各方案参数。切换任务时，已有结果继续注明原任务，并标出待运行任务；编辑链路会清除已失效的测量。旧工程从结果中的任务信息恢复选择器，旧结果没有时间戳时显示“历史结果（未记录时间）”。

## 窄屏与键盘

不超过 1000 CSS 像素宽时，使用积木库、链路、参数、结果四个入口，默认展示链路。选中积木即打开底部参数抽屉，完成或 Esc 返回；大屏继续使用右侧参数栏。窄屏全局导航可以横向滚动，各页面链接保持可用。

次要积木按钮在选中、悬停或键盘聚焦时显示。输入值验证会打开对应参数面板；运行中禁用编辑及会修改链路的工具，停止/暂停仍可使用。原有 150 个可添加模块、仿真算法、工程 schema 1/2、分支与扫描功能保留，无新增生产依赖。

## 实现与验收

`web/communication-layout.js` 移动现有 DOM 节点，复用原事件处理和 API，不复制控件或建立第二套工程状态。`communication-layout.css` 按布局层覆盖旧样式。分析页签、抽屉与大图切换时根据显示尺寸重新绘制 Canvas；标签页采用 ARIA tab/tabpanel 语义，弹窗使用原生 dialog 焦点管理。

界面偏好不改变通信工程的科学参数。任务选择记录为 `rfTaskId`，结果在 `rfComparisons` 中追加 `completed_at` 和 `context`，保持旧工程可读。运行任务时冻结任务选择，结果标题从运行完成的数据取得。

验收日志位于 `logs/communications-v046/`，隔离服务数据位于 `debug/v046/`。浏览器验收涵盖全部示例 Build/Run、七项任务、工程恢复、撤销、参数验证、单步、多帧、导出，以及桌面和 390 像素窄屏布局；后端运行原回归套件，新安装包按 `scripts/verify_release.py` 验证。

## 升级

保留 `data/`、`uploads/`、`outputs/`，更新源码并重启服务，或重新构建 Docker，然后刷新浏览器。启动命令和 `config/communications.json` 沿用现有配置；`config/release.json` 记录版本号。
