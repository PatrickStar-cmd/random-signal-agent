| 位置 | 新增技术 |

| 信道 | 载波频偏、Wiener 相位噪声、未知帧延迟、复波形 AWGN、复 FIR 多径、Rayleigh/Rician 衰落 |
| 解调器 | 六种新制式的配对解调；BPSK/QPSK/16QAM Max-log LLR；匹配滤波、Gardner、粗频偏、Costas/PLL、相关帧同步、复数 LMS/NLMS/RLS/DFE、CMA、导频 LS、OFDM 接收和一体化接收器 |
| 收转换器 | CRC 检查、解扰、三个信源编解码对的重构、软判决 Viterbi、LDPC 归一化最小和 |

数字单载波的完整搭建示例：

`比特 → CRC → 卷积码 → QPSK 映射 → 公共前导 → RRC 成形 → 频偏/延迟/噪声 → 粗频偏 → 匹配滤波 → Gardner → 载波环 → 帧同步 → QPSK 软解调 → 软 Viterbi → CRC 检查 → 信宿`

“完整复基带接收器”把粗频偏、匹配滤波、Gardner、载波环和帧同步组合在一个积木中。逐块版本可以在“处理中间结果”中观察各积木输出。

周期导频位于组帧之前；接收端先完成帧同步，再估计导频。训练均衡位于帧同步之后；CMA 位于帧同步之前，由帧同步消除盲均衡的相位不确定性。收转换器按照发转换器的相反顺序排列。线路码/PAM 可以与 CRC、扰码和新增信源编码组合；LLR 与 LDPC 使用数字 PSK/QAM 路径。

## 🔀 比特与信源处理

### CRC、PRBS 与扰码

CRC 把比特串看成二进制多项式，逐位移位并按反馈条件异或生成多项式，得到附加在数据后的校验位。接收端重新计算并比较；CRC 检查与纠错译码是两个独立步骤。

本版的确定约定：

| 制式 | 多项式（省略最高项） | 初始寄存器 | 反射 / 最终异或 | `123456789` 校验值 |
| --- | --- | --- | --- | --- |
| CRC-16/CCITT-FALSE | `0x1021` | `0xFFFF` | 均关闭 | `0x29B1` |
| CRC-32/MPEG-2 | `0x04C11DB7` | `0xFFFFFFFF` | 均关闭 | `0x0376E6E7` |

两者都按最高位先发，也支持非整字节比特流。每次 Run 是一帧，结果中显示 `crc_pass` 和 CRC 检出的错误帧数。

LFSR 每次输出寄存器最低位、向右移一位，把反馈位写入最高位。PRBS7/15 的反馈为第 0、1 位异或；PRBS9 为第 0、4 位异或。非零初态范围为 `1…2ⁿ−1`，周期为 `2ⁿ−1`。同步扰码采用 `发送位 XOR PN 位`，接收端用相同初态再次异或。相关视图显示当前 PN 信源整段数据的周期自相关；完整周期的非零延迟归一化值为 `−1/(2ⁿ−1)`。

### 压扩 PCM、DPCM 与增量调制

压扩先把输入除以量程归一化到 `[-1,1]`，压缩幅值后均匀量化，接收端使用逆函数。μ 律使用 `sign(x) ln(1+255|x|)/ln(256)`；A 律使用 `A=87.6` 的分段线性/对数函数。本实现展示连续压扩加可选位数量化，不使用 G.711 的字节段码封装。量程外输入饱和，结果统计压扩 PCM 饱和样本数。

DPCM 的发送端预测值为 `a × 上一个重构样本`，量化当前样本与预测值的差，再把量化差加回预测值。收端进行相同递推。使用重构值作为反馈使收发状态一致；位数、残差量程和预测系数控制精度与过载。

增量调制每个样本只发一位：高于当前重构值则加 `Δ`，否则减 `Δ`。小步长可以减小平缓区的颗粒噪声，大步长能跟随更陡的变化。它的采样率沿用模拟信源设置。

## 📡 数字调制与软信息

OOK 把 0 映射到 0、1 映射到 `√2`，等概率输入平均符号能量为 1。2FSK 在每个码元发送归一化频率 `±1/(2T)` 的正交复指数；接收器选择相关实部比较的相干检测，或相关模平方比较的非相干检测。

DBPSK 的相位增量为 0/π；DQPSK 的 `00,01,10,11` 对应 `0,π/2,−π/2,π`，使用 Gray 邻接。两者实际发送一个参考符号，接收端对相邻符号作共轭相乘，再按差分相位判决。

MSK 的瞬时频率为 `±1/(4T)`，即调制指数 `h=1/2`，相位连续积分。GMSK 先用高斯滤波器平滑双极性 NRZ 频率指令，再积分相位；BT 决定平滑程度，滤波器跨度为 4T。接收端实现相位差鉴频与逐码元积分，适合比较 BT、频谱与误码表现；并非最大似然序列检测器。

LLR 定义为 `ln(P(bit=0)/P(bit=1))`。Max-log 软解调计算到标记 1 与标记 0 的最近星座点距离平方之差，再除以复噪声方差 N₀。正值支持 0，负值支持 1，绝对值表示可信度。`noise_variance` 是判决点的复噪声方差；匹配滤波、衰落补偿后的实验需按该位置配置。只有一个符号 AWGN 且无其他损伤的参数扫描会自动同步对应的软解调方差，其余链路保留用户的判决点方差设置。

软 Viterbi 保持原卷积码 `(7,5)₈`、约束长度 3、两个零尾位，使用 LLR 作为分支代价，最后回溯零状态。硬判决版本继续保留用于同链路比较。

### LDPC 教学码

本版提供确定的系统 IRA `(128,64)` 码，校验矩阵 `H=[A B]`。A 的第 j 列在行 `j,(j+1) mod 64,(j+9) mod 64` 为 1；B 的主对角线与下副对角线为 1。先计算 `A×数据 mod 2`，再累加异或得到 64 个校验位；不足 64 位的数据尾部补零，译码后按公开帧长度去掉填充。

接收端采用 flooding 归一化最小和：校验节点输出其余输入符号的乘积和最小幅值，乘以归一化系数；变量节点汇总通道 LLR 与校验消息。每次迭代检查 `H×判决码字 mod 2`，全零即停止。可设 1–60 次迭代，输出实际迭代数及未通过校验的码字数。它是可复现的教学矩阵，不标注为某个通信标准的 LDPC。

## 🎛️ 完整接收机

RRC FIR 先归一化到单位能量，符号上采样后与滤波器卷积；接收端使用匹配滤波器。每码元可选 4/8/16 点，滚降系数与跨度共同决定频谱和有限截断误差。无组帧的理想链路按公开滤波延迟对齐；未知延迟或时钟漂移链路需要实际发送的公共前导。

Gardner 先扫描一个码元内的平均采样能量寻找初始相位，再用“前后符号差 × 中点样本的共轭”的实部形成误差，经 PI 环更新采样位置和周期。实现对 I/Q 两路联合处理，显示真实采样相位与末段时钟速率估计。

粗频偏估计将 BPSK 平方、QPSK 四次方，再对 FFT 峰值插值得到载波频偏。幂次法有频率模糊：捕获范围约为采样率除以两倍幂次。Costas/判决引导 PLL 用接收点和最近星座点的相位差更新二阶环，跟踪剩余相偏与频偏。

公共前导由固定公开随机种子 43017 和该制式的星座生成，长度可选 128/256/512/1024。相关帧同步搜索接收符号与前导的归一化相关峰，输出锁定状态、峰值及起点。对齐后由前导最小二乘估计复增益，消除相位模糊；负载不会作为参考输入。未达到门限的帧仍输出检测状态与统计，计入 FER。

复数自适应均衡支持 LMS、按输入能量归一化的 NLMS、递推最小二乘 RLS；线性 FIR 和带判决反馈的 DFE 共用训练前导。训练结束后按判决继续更新。CMA 则最小化 `(R−|y|²)²`，`R=E|星座|⁴/E|星座|²`，不使用训练目标；界面显示恒模代价收敛。上述均衡均在符号采样率工作。

## 🌊 衰落、导频与 OFDM

载波频偏逐点乘 `exp(j2πΔft)`；相位噪声累加独立高斯相位增量。未知帧延迟包含整数零填充和分数采样插值。复 FIR 多径使用实部/虚部抽头及整数采样间隔，不把发送端干净负载传给接收估计器。

Rayleigh 在零多普勒时为帧内固定复高斯增益；非零时用 32 个随机角度和相位的散射波叠加产生时变衰落。Rician 在散射部分上加入直达波，按 K 因子分配直达与散射功率，平均总功率为 1。当前是单个平坦衰落过程，复 FIR 多径可另外串联。

周期导频在每组数据前插入已知 `+1` 符号，LS 估计等于“接收导频 / 已知导频”。对复增益的实部和虚部分别插值，随后以正则化倒数补偿数据。导频间隔可调，用于比较时变衰落下跟踪精度与开销。

OFDM 可选 32/64/128 点 FFT；0 号子载波留空，其余 `索引 mod 4 = 1` 为梳状导频，其余放置 PSK/QAM 数据。帧首实际发送一整个已知 BPSK 训练 OFDM 符号。IFFT 乘 `√N` 保持能量，再复制尾部 CP 到前面。

收端用已知训练波形定位起点，去 CP，FFT 除以 `√N`，从训练符号作逐载波 LS 信道估计；随后按每载波复增益均衡，并用梳状导频跟踪公共相位。CP 应覆盖多径延迟扩展。资源网格显示均衡后前 16 个 OFDM 符号的幅度；结果 JSON 包含复网格、信道估计、载波索引和 PAPR。全局 `symbol_rate` 在 OFDM 中作为子载波间隔，采样率为 `symbol_rate × NFFT`；发送块时长含 CP。

## 📊 性能实验与统计口径

Build 后展开“批量性能实验”，选择噪声积木、横轴、起止值、步长、每点最大帧数和目标误比特数。每点满足目标错误数或帧数上限即停止；各点使用相同的 `seed + 帧序号` 序列。可保存 6 条对比曲线，按当前最后一次扫描的横轴单位分组显示，支持 BER/SER/FER 与完整 JSON/CSV 导出。

Eb/N₀ 以起始种子的发送参考帧总能量除以信息比特数标定，包含前导、导频、CP、编码尾位和填充。后续种子使用同一参考标定，不在衰落后重新测功率。复基带噪声方差为 `Eb / (Eb/N₀)`；实采样基带的每点噪声方差使用其一半。原生 SNR/Es/N₀ 模式直接扫描该积木已有参数。界面/JSON 返回换算后的噪声 dB 及标定信息。

BER 按累计错误位/总位，SER 按累计错误符号/总符号，FER 按错误帧/总帧统计；同步未锁定也计为错误帧。另行记录 CRC 检出的错误帧数。95% Wilson 区间按二项比例给出，编码后相关错误的精度评估还应增加独立帧数。零错误点画空心区间上界，同时表格保留实际观测值 0。无编码、无额外损伤的 BPSK/QPSK AWGN 链路叠加理论 BER 虚线。

配置 `config/communications.json`：`max_wave_samples=262144` 限制复波形中间数组；`max_sweep_points=21`、`max_sweep_frames=100`、`max_sweep_runs=300`、`max_sweep_seconds=40` 控制扫描资源。达到时间限制返回已累计结果和 `complete=false`；不会把部分扫描标记为完成。原来的块数、比特数、信源数、绘图点数和并发限制继续有效。

接口：`POST /api/communications/sweep`，JSON 为 `{program, token, settings}`。settings 字段为 `block_id, mode(native/ebn0), start, stop, step, frames, target_errors`。与 Run 共用仿真并发槽，配置令牌变化后需要重新 Build。
