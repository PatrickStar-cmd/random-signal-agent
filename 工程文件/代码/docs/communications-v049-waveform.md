# v0.4.9 新波形、射频补偿、突发同步与 Polar 编码

本专题新增 13 个积木与 9 个预设，沿用积木属性面板、Run 观察点和海洋风格射频分析区。

## 🌊 DFT-s-OFDM / SC-FDMA

推荐先运行「新波形 · DFT-s-OFDM 连续映射」，再选择交织映射和「波形对照 · 相同资源的 OFDM」。三种工程使用相同调制、FFT 点数、循环前缀与已分配载波数。

链路由独立积木组成：

`QPSK / QAM → DFT 扩展 → SC-FDMA 子载波映射与 IFFT → 信道 → FFT 均衡与解映射 → IDFT 解扩 → 解调`

- DFT 扩展使用 `FFT(x)/sqrt(M)`，接收 IDFT 使用 `IFFT(X)*sqrt(M)`，保持分组总能量。
- 子载波映射支持连续 LFDMA 与交织 IFDMA。FFT 点数为 32、64、128 或 256；分配载波为 8、16、32 或 64，至多占一半频带。
- 两个相同的公开 QPSK 训练 OFDM 符号用于帧定位、信道最小二乘估计和噪声残差测量。
- 均衡采用 `conj(H)/(abs(H)^2 + regularization)`，输出解映射符号；末组填充在 IDFT 解扩后移除。
- 射频测量保留整帧 Welch 功率谱、CCDF、PAPR 与误码统计；新波形面板展示具体分配载波和接收估计信道。

## 🔧 回环训练与数字预失真

推荐运行「射频 · 回环训练与数字预失真」，与「射频对照 · 记忆功放输出」比较。操作链为：

`发送波形 → 功放回环训练采集 → DPD 逆模型系数估计 → 数字预失真器 → 记忆多项式功放 → 信道`

功放采用奇数阶记忆多项式：

`y[n] = Σ_m Σ_p a[m,p] x[n-m] |x[n-m]|^(p-1)`，其中 `p = 1,3,5`。

每条延迟支路包含线性、三阶和五阶项；参数面板提供输入回退、三阶系数、五阶系数、延迟支路强度和 1–5 点记忆深度。系数包含复数分量，同时产生 AM/AM 与 AM/PM 变化。连续帧执行保留功放及预失真器的历史样本。

回环采集积木用固定公开复训练序列驱动相同功放，并保存实际输入和输出。DPD 拟合使用输出波形组成多项式矩阵，以输入波形为目标求解岭回归逆模型；支持 3、5、7 阶与可选记忆深度。应用阶段将逆模型作用于当前业务波形。

「新波形、同步与现代编码」面板提供训练误差、复数系数、幅度响应、相位响应、处理前后功率谱与 JSON 导出。射频仪表可进一步比较主信道及邻道功率、峰均比和接收 EVM。训练与运行功放参数在 Build 时配对核查。

## ⏱️ 突发捕获与采样时钟恢复

推荐运行「同步 · Schmidl–Cox 与采样时钟」或「同步 · Zadoff–Chu 与采样时钟」。默认使用 64 点 FFT、48 个有效载波，为采样钟变化保留频带保护区。

发送端在 OFDM 波形首尾各插入一个公开重复标记。Schmidl–Cox 模式使用相同的两个复训练半段，Zadoff–Chu 模式使用偶数长度、根为 1 的 ZC 半段。前导半长为 32、64 或 128。

接收过程：

1. 对两个半段计算相关，得到重复前导度量及粗频偏。
2. 使用公开模板相关定位起始标记，相关曲线解释重复结构和定时峰。
3. 在预期帧尾附近定位第二个公开标记，按两标记的实际间隔估计采样时钟比例。
4. 用首尾标记的接收样本联合拟合起点、时钟 ppm 和载波频偏，再按前后标记相位差细化频偏。
5. 使用 97 抽头窗化 sinc 插值回到发送采样栅格，移除两端标记后交给 OFDM 接收。

接收估计使用公开标记、标称有效波形长度和实际接收 I/Q；输出包含捕获状态、起始采样、估计 Hz、估计 ppm、前导拟合误差和两条定时度量曲线。录波回放通过接收积木的「录波有效波形长度」配置进行同样的同步恢复。重复半段的粗频偏捕获区间为 `±Fs/(2L)`，L 为前导半长；通过调整 L 形成捕获范围与相关长度实验。

### SigMF 保存与自动接收

SC-FDMA 录波保存 FFT/CP、载波数、连续／交织映射、有效符号数、DFT 分组与解扩后的有效长度。突发录波同时保存前导类型、半长、有效波形长度、搜索窗口和采样频偏搜索范围。导入后自动连接所需的同步、SC-FDMA 接收和 IDFT 解扩积木。

导出边界跟随实际信号处理状态：发送端 DFT 输出和 SC-FDMA 接收输出保留待执行 IDFT 信息；解扩后的符号直接进入解调。突发同步前保留前后标记信息，同步恢复后的 OFDM 波形继续 FFT 接收。录波也支持在接收中间位置再次导出与导入。工程「补齐接收端」按录波元数据恢复相应步骤和公共前导参数。

## 🛡️ Polar 编码与 SC / CRC-SCL

链路为：

`比特 → Polar 编码 → BPSK / QAM → 信道 → LLR 软解调 → Polar SC / CRC-SCL → 信宿`

- 母码长度 N 支持 64、128、256；K/N 支持 1/4、1/2、3/4，K 包含每码字 16 位 CRC。有效载荷长度为 K−16。
- 采用公开 BEC 设计参数计算子信道可靠度，递归使用 `z_bad=2z−z²`、`z_good=z²`；选择可靠度最高的 K 个位置放置数据及 CRC，其余冻结为 0。
- 编码使用自然顺序的 `F` 张量幂蝶形变换；SC 译码递归计算精确 box-plus 与 g 节点 LLR。
- CRC-SCL 保留 2、4、8 或 16 条候选路径，使用负对数似然增量更新度量，最终选择通过 CRC 的最小度量路径。所有码字均保存 CRC 结果和译码耗时。
- 新分析面板展示前 64 个极化位的冻结／信息类型、幸存路径数、路径度量和各码字 CRC 结果。
