# 可爱海洋界面（v0.3.0）

青蓝、薰衣草紫与珊瑚粉多层渐变搭配蓝紫、薄荷色圆角卡片。欢迎区使用 AI 生成的立体鲸鱼、海星与波纹，1536 × 1024 的透明 WebP 约 143 KiB；导航与分区标题适量添加装饰表情。图表采用浅色底、深色文字和可区分的曲线颜色。素材、完整生图提示词与交付编码说明见 [visual-assets.md](visual-assets.md)。

Agent 完整方法比较回复展示分析结论、推荐方法、真实指标及下一步。全部方法和参数保留在可展开区域；数值来自该条消息自身，不取当前工作区，历史对话保持原值。未匹配的普通回复及流式未完成文本继续使用 Markdown，标题、段落、列表和表格统一增加间距。

Edge 验收覆盖六个分区及 320、390、720、768、1024、1440、1920 px 宽度，无页面横向溢出或脚本异常。实际生成保存两个实验，完成跨实验对比、故障诊断/验证、历史报告预览及两组 PDF 下载。核对六种方法原始数据、历史值、未完成回复回退、HTML 转义和展开状态；本机实际字体为 STZhongsong 与 Times New Roman。静态预览同步配色、波纹与框线。

## 操作入口

启动方式与以前相同：运行 `scripts/start_server.ps1` 或 `scripts/start_server.sh`，打开服务地址。

| 分区 | 用途 |
| --- | --- |
| 信号工作区 | 对话、快速上传、麦克风、波形频谱、统计指标、方法选择与建议 |
| 模板与实验 | 生成信号、比较方法、保存与恢复快照、导出完整实验包 |
| 导入数据 | 预览 CSV/TXT，确认列映射与时间单位；成功后进入模板与实验 |
| 对比与报告 | 对比 2–4 个快照并下载报告 |
| 诊断实验室 | 时频定位、异常证据、故障注入与验证试验 |
| 模型与设置 | 模型 API 配置、任务队列、存储清理 |

对话框上方的示例按钮只填写指令，确认后点击“发送”执行。顶栏随滚动保持可见；窄屏排列为两行。桌面为对话、图表、工具箱三列，中等屏幕为两列，手机为单列。

## 实现方式

`web/ocean.css` 管理新的布局、层级、间距和装饰；已有组件样式及 Canvas 绘制颜色同步适配浅色背景。`web/ocean.js` 通过 `hidden` 切换六个分区，保留原 DOM、表单和实验状态，不重复挂载表单，也不增加构建工具或运行依赖。

入口保留 HTML 锚点，支持直接链接、键盘、浏览器前进/后退。显现分区后触发尺寸更新，以正确的画布尺寸重绘波形、时频图及当前验证试验。试验显示缓存匹配令牌、事件、方法、区间与指标；恢复的快照没有显示样本时，仍提示重新验证。禁用 JavaScript 时各分区保持可见。

提供跳到工作区链接、清晰焦点样式、当前导航提示；降低动态效果偏好会关闭过渡与动画。没有引入远程字体、遥测或图片服务。

## v0.4.0 通信实验室分区

导航增加“📡 通信实验室”，现有六分区入口保留。桌面左侧编程/右侧可视化，窄屏上下排列。积木箱按信号处理顺序分为蓝色信源、紫色发转换器、粉色调制器、橙色信道、青色解调器、薄荷色收转换器六类，拼接积木沿箭头形成单条链路；信宿固定在最后。链路标题同步展示完整处理顺序。原生拖动和按钮添加/移动并存，表单参数有标签和范围，撤销/重做、Build/Run 与导出集中在编程区。

接收区以 CRT 外框和低帧率雪花表示无结果，Build 不显示假信号；Run 后替换为带坐标的真实输出，可叠加源参考、浏览完整接收序列并显示错误位。星座图与信道 I/Q 使用不同观察点的明确标签，指标展示全帧统计。隐藏分区/页面时停止雪花，系统减少动态效果时使用静止雪花；无声音或闪烁背景。

沿用华文中宋/Times New Roman 回退、海洋渐变和 4 px/2 px 分层边框。切换分区保留状态，重绘不改变浏览窗口；修改工程使已构建状态与旧结果失效。截图及使用指南见 [communications-lab.md](communications-lab.md)，验收日志为 `logs/communications/browser.log`。

当前源码新增六种模拟调制：沿用调制器/解调器分类和表单，SSB/AM 下拉框显示有含义的方法名称。直接模拟结果自动切换为 RMSE、样本数、输出信误比与复包络误差，并显示 AM 过调制或角调制零幅值警告；分析页显示已调 I/Q、已调频谱与信道 I/Q，隐藏离散星座页。切回数字实验恢复原指标和星座页；标签在窄屏自动换行。频谱明确标注相对载频 Hz，波形区分模拟采样与数字符号时钟，验证记录在 `logs/communications-analog/browser.log`。

第四章实基带扩展将十种线路编码/译码加入发/收转换器，波形形成与抽样判决加入调制/解调器，沿用六类颜色和添加/排序交互。接收区按结果类型显示发送波形、发送频谱、信道波形、接收眼图四个分析页；原复符号结果恢复星座和 I/Q，模拟结果恢复已调波形/频谱。基带指标显示译码后 BER、实际电平码元数、有效码率和电平 RMSE，详情列出 fs=Rs×sps、线路展开、违例、均衡前后 RMSE 及系数。参数变化立即使 Build/Run 结果失效。

同步与自适应均衡增加“时钟跟踪”和“均衡收敛”两页，按实际结果显示；关闭功能或切回旧实验时隐藏，并恢复可用的波形/星座页。详情显示公共前导与数据占比、初末相位/ppm/抖动、反馈系数、训练 MSE 和更新次数。误差图明确区分公共训练与后续判决误差，不能当作真实 BER。新默认字段在旧工程中缺省时，表单使用 catalog 默认值显示，显式空值仍可继续编辑。七个示例、LMS 参数与冻结、训练不足校验、草稿刷新、同步关闭及旧 NRZ 视图恢复通过；320/390/1440 px 无横向溢出和脚本错误。截图见 [同步与均衡指南](receiver-recovery.md)，日志在 `logs/communications-recovery/browser.log`。
