# 可爱海洋界面（主分支新增）

蓝紫色背景搭配白色圆角卡片，鲸鱼、海星与波纹为项目原创 SVG。图表采用浅色底、深色文字和可区分的曲线颜色；装饰只出现在欢迎区。

## 操作入口

启动方式与以前相同：运行 `scripts/start.ps1` 或 `scripts/start.sh`，打开服务地址。

| 分区 | 用途 |
| --- | --- |
| 信号工作区 | 对话、快速上传、麦克风、波形频谱、统计指标、方法选择与建议 |
| 模板与实验 | 生成信号、比较方法、保存与恢复快照、导出完整实验包 |
| 导入数据 | 预览 CSV/TXT，确认列映射与时间单位；成功后进入模板与实验 |
| 对比与报告 | 对比 2–4 个快照并下载报告 |
| 诊断实验室 | 时频定位、异常证据、故障注入与验证试验 |
| 模型与设置 | 模型 API 配置、任务队列、存储清理 |

对话框上方的示例按钮只填写指令，确认后点击“发送”执行。顶栏随滚动保持可见；窄屏排列为两行。桌面为对话、图表、工具箱三列，中等屏幕为两列，手机为单列。

## 实现方式

`web/ocean.css` 管理新的布局、层级、间距和装饰；已有组件样式及 Canvas 绘制颜色同步适配浅色背景。`web/ocean.js` 通过 `hidden` 切换六个分区，保留原 DOM、表单和实验状态，不重复挂载表单，也不增加构建工具或运行依赖。

入口保留 HTML 锚点，支持直接链接、键盘、浏览器前进/后退。显现分区后触发尺寸更新，以正确的画布尺寸重绘波形、时频图及当前验证试验。试验显示缓存匹配令牌、事件、方法、区间与指标；恢复的快照没有显示样本时，仍提示重新验证。禁用 JavaScript 时各分区保持可见。

提供跳到工作区链接、清晰焦点样式、当前导航提示；降低动态效果偏好会关闭过渡与动画。没有引入远程字体、遥测或图片服务。

## 参考与验证

参考 [LobeHub 设计系统](https://github.com/lobehub/lobehub/blob/canary/DESIGN.md) 的语义颜色、字体层级、统一间距与渐进展示，以及 [shadcn/ui 仪表盘](https://ui.shadcn.com/examples/dashboard) 的功能分区和卡片组织。海洋配色与插画独立设计，未复制它们的代码或品牌素材。

浏览器验收覆盖生成/保存/复制、跨快照对比、图表缩放、统计展开与窄屏多曲线图例留白、诊断与验证曲线在分区切换后保留、模拟模型测试及对话、导入后的分区跳转、示例不自动发送、输入保留、锚点与键盘导航。320、390、720、768、1024、1280、1920 像素宽度的六个分区均无页面横向溢出，未发现 JavaScript 异常。诊断回归 16 项通过；静态预览 320、390、1440 像素宽度均无横向溢出。修正了任务结束仍显示“执行中”的提示。

调试截图及独立测试服务数据放在 `debug/ocean-ui/`，说明见其 `note.md`；浏览器检查覆盖写入 `logs/ocean-ui/browser.log`，测试服务日志覆盖写入 `logs/ocean-ui/server.log`。只使用本地模拟模型，不消耗真实 API 额度。

GitHub Pages 提供同风格的截图与固定实验结果预览；交互工作区依然需要 Python 后端。此更新尚未包含在已发布的 v0.2.6 ZIP 中。
