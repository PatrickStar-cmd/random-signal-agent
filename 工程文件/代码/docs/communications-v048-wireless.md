## 🔍 1. 排序 SIC：逐层恢复空间流

1. 载入“多天线 · 排序 MMSE-SIC”，点击 Build、Run。
2. 查看两条恢复流的星座、估计矩阵、检测次序和每层消除后的残差功率。
3. 保持发送结构、信道和种子，建立 ZF、MMSE、ZF-SIC、MMSE-SIC 接收分支，比较 BER 与 EVM。
4. 将信道增益改成 `1,0.8,0.2,1`，降低 SNR，观察先检测可靠层对后续恢复的影响。

接收模型为 `y = Hs/√2 + n`。接收端从正交训练最小二乘估计 H 和噪声方差，再按各层的检测后信干噪比排序。每次计算 ZF 或 MMSE 权重，判决当前符号，从接收向量减去该层的重构波形，然后检测剩余空间流。帧长度标识补零资源，检测器据此保留实际载荷边界。

## 🚗 2. 移动与相关信道：让导频跟随 H(t)

1. 载入“移动多天线 · 周期导频跟踪”，查看时域信道轨迹和导频估计。
2. 从默认 `2.4 GHz、3 km/h、8 个数据时隙间隔` 开始，逐步提高速度，再缩短导频间隔。
3. 调整收、发相关系数，比较矩阵条件数和各空间流的恢复质量。
4. 开启连续多帧，观察信道时间轴延续、导频重新估计和接收结果。

最大多普勒频率为 `fd = (速度 / 3.6) × 载频 / c`。每对天线使用 32 个散射角对应的正弦分量生成 Clarke/Jakes 衰落；相关模型为 `H(t) = Lr G(t) Ltᵀ`，其中 `Lr`、`Lt` 为收发相关矩阵的 Cholesky 因子。连续帧保留散射相位和全局采样位置。

发送端在数据组之间及帧尾插入正交导频。接收端逐组估计复矩阵，再对每个矩阵元素按时间线性插值，逐时隙执行 ZF、MMSE 或 SIC。噪声功率由导频拟合残差计算。

## 🌊 3. MIMO-OFDM：逐子载波估计与分离

1. 载入“宽带多天线 · MIMO-OFDM ZF”，运行默认 `32 点 FFT、8 样本 CP、0/3/7 样本多径`。
2. 查看发射资源矩阵、各子载波的 2×2 信道估计和恢复空间流。
3. 将接收器切换为 MMSE-SIC，改变路径功率与 SNR，比较频率选择性衰落下的检测结果。
4. 调整 FFT 与 CP；Build 会核对 CP 对最大路径延迟的覆盖。

两空间流按 `1/√2` 归一化，在各自天线上执行单位酉 IFFT 与 CP 插入。每条时延路径应用一个 2×2 复矩阵并对实际样本卷积。接收端去 CP、FFT，使用四个分天线正交训练 OFDM 符号逐子载波估计 H[k] 和噪声方差，再独立检测每个资源单元。

采样率为 `FFT 点数 × 工程符号率`，一个 OFDM 时隙持续 `(FFT 点数 + CP) / 采样率`。发送能量合计两个天线，接收结果恢复为原始数据顺序。

## 👥 4. OFDMA：独立用户、队列与实际吞吐

1. 载入“多用户 · OFDMA 加权公平”。默认三个信源分别产生 256、384、256 位，成为三个独立用户。
2. 查看资源图的用户颜色与功率、各用户队列长度、BER、整包交付吞吐和时延。
3. 修改资源权重 `1,2,1`、每载波功率或用户信道增益，比较轮询、加权公平、最长队列以及固定频带分配。
4. 增大包到达间隔观察稀疏业务，缩短间隔观察队列积压与调度差异。
5. 将中间用户 SNR 降低，观察其接收包和实际吞吐变化。

每个用户保持独立源边界、包到达时刻、待发送队列与接收判决。调度器将队列符号放入互斥的子载波资源，按用户功率缩放，执行 IFFT 和 CP 插入。同一下行波形分别通过各用户复信道及独立噪声；每个用户从公共训练估计自身信道，再提取、均衡并判决自己的资源。

- **固定频带**：按权重划分频带，各用户使用自己的载波。
- **轮询**：在当前有数据的用户之间轮流分配资源。
- **加权公平**：优先服务“已发送符号数 / 权重”最小的用户。
- **最长队列**：每次优先选择当前待发送符号最多的用户。

`delivered_bits` 累计整包全部比特恢复正确的载荷；吞吐为该载荷除以包含训练的实际发送时长。包时延从到达到最后一个符号发送完成计算。公平性使用各用户实际吞吐的 Jain 指数 `(ΣR)² / (用户数 × ΣR²)`。用户数为 2–4，各源比特长度按 PSK/QAM 星座位宽对齐。

## 🐟 5. FHSS：联合捕获与解跳

1. 载入“跳频 · 同步与抗窄带干扰”，运行并查看跳频轨迹、码相位相关曲线和样本延迟峰。
2. 默认频点为符号率的 `−3、−2、−1、1、2、3` 倍，每跳 4 个符号，16 样本/符号。
3. 调整发送初始码相位和信道样本延迟，运行后核对捕获结果。
4. 改变窄带干扰的频率和幅度，观察干扰与跳频资源相交时的接收表现。
5. 开启连续多帧，观察跳频码序列位置延续和每帧重新捕获。

发送端按可重现的 31 跳伪随机序列切换载波。接收端用公共训练联合搜索全部码相位与指定范围的样本延迟，按归一化相关峰定位；随后下变频、逐符号积分，再以训练估计复增益。每个符号总能量保持为 1，波形采样率为 `每符号样本数 × 工程符号率`。低置信捕获记录 `detected=false` 并计入 FER，最佳候选继续参与实际译码；包级 CRC 决定 ACK / NACK 和重传。

## 📊 输出与复核

JSON 中的复数组统一保存为 `{i, q, shape}`：

| 字段 | 数据内容 |
|---|---|
| `advanced.wireless[发送积木].full_tx` | 完整发送样本，时间×天线 |
| `advanced.wireless[信道积木].full_rx` | 完整接收样本，时间×天线或用户 |
| 接收器 `stream_symbols`、`stream_counts` | 两条恢复空间流及各流有效符号数 |
| 接收器 `sic` | 层次、硬判决、消除后的残差功率 |
| 动态信道 `channel_trace`、`time_seconds` | 完整 H(t) 与秒单位时间轴 |
| 跟踪器 `tracking` | 导频时隙、估计矩阵、数据时隙和条件数 |
| MIMO-OFDM `grid`、`recovered_grid` | 时隙×子载波×天线/空间流 |
| OFDMA `resources`、`users`、`fairness` | 资源所有者、功率、用户队列/包/吞吐和公平性 |
| FHSS `hops`、`sync` | 跳频轨迹、捕获相位、延迟和相关曲线 |

运行 `python scripts/test_communications_spatial.py` 可复核 11 项核心测试；`python scripts/test_communications_wireless.py` 覆盖原有 8 项无线测试。新增 11 条默认预设端到端运行的 BER 均为 0。专项测试包含连续信道逐点一致性、相关系数、导频跟踪、逐载波矩阵恢复、独立用户噪声影响、强单音干扰恢复、低置信捕获和擦除帧、参数检查。
