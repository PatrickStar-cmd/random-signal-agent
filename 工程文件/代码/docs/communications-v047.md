打开实验库，选择“业务 · 音频 / ADPCM”“业务 · 图像 / RS 纠错”或“业务 · 文件 / CRC / BCH”，点击 Build、Run，在业务观察区播放、比较或下载信宿输出。选择相应信源积木后，可上传自己的文件；图像转换为指定尺寸灰度像素，音频转换为工程使用的单声道 PCM16。

Huffman 实验使用“信源编码 · 概率 / Huffman 编码树”：先观察默认偏斜分布，再将概率改为相近数值，比较平均码长和包含码表开销的实际长度。RS 突发噪声实验结合块交织，调整坏状态持续时间，比较恢复图像、误码率和纠错字节数。

### 七个可直接运行的实验

1. **扩频 · 码捕获与抗窄带干扰**：运行 BPSK → DSSS → 窄带干扰 → 捕获 → 解扩，查看恢复码相位和相关峰；调整扩频倍率与干扰频率，比较 BER 和 EVM。
2. **扩频 · RAKE 多径合并**：运行 QPSK 扩频多径链路，观察三个估计延迟；将 RAKE 换成相关解扩，使用同一种子比较接收误差。
3. **分集 · SIMO 选择合并**：比较接收支路估计功率和所选天线；改变固定复增益或切换块 Rayleigh。
4. **分集 · SIMO 最大比合并**：将接收积木切换为 MRC，保持种子与信道参数，比较 EVM 与 BER。
5. **分集 · Alamouti 2×1**：观察两个发送天线的两时隙编码、训练估计和恢复符号；逐步降低信噪比。
6. **多天线 · 2×2 MIMO ZF**：观察并行流、矩阵奇异值与条件数；将矩阵两列逐渐设为相近数值，观察噪声增强。
7. **多天线 · 2×2 MIMO MMSE**：沿用 ZF 工程的信道与种子，切换检测器，比较低 SNR 下的恢复误差。

### 能量、时间与接收估计

DSSS 将一个符号乘以长度为 L 的 ±1 PN 序列，再除以 √L。因此扩频前后每个符号的总能量相同，码片率为符号率的 L 倍，处理增益标为 10 log₁₀L dB。捕获器扫描本地码相位及帧延迟，以公共训练前导的归一化相关峰定位；解扩后使用训练样本估计并校准复增益。RAKE 在相关峰附近构建延迟训练矩阵，通过最小二乘估计路径，选择最强指支路，以共轭增益加权。

空间链路的矩阵形状为“时隙×天线”。Alamouti 和 MIMO 每天线符号按 1/√2 缩放，发送总功率按两天线之和计量。多天线信道采用 `Y = X Hᵀ + N`，接收端从公共正交训练估计 H，各接收天线噪声独立。SC 选择最强支路；MRC 按共轭增益合并并除以总增益功率；Alamouti 使用两个时隙的共轭关系恢复符号；ZF 与 MMSE 分别采用逆矩阵和含训练残差噪声方差的正则矩阵。

通用波形视图展示第 1 根天线，阵列结果保留所有发送、接收天线的完整数组、训练参考与实测训练、估计信道矩阵及恢复符号。发送能量汇总所有天线，持续时间按实际发送时隙计算。接收算法使用公共训练与接收样本估计参数。

## 🧮 工程变量与二维扫描

定义 `Rs=1000`、`sps=8`、`Fs=Rs*sps`，将符号率绑定到 `Rs`、采样率绑定到 `Fs`，或将积木数值参数绑定到变量公式。公式支持变量依赖、括号和四则运算、整除、余数、幂。应用变量后 Build，修改一次即可更新共享参数。工程快照保存变量定义和绑定关系。

二维扫描选择两个参数轴及各自的数值列表，设置每点帧数，运行后显示 BER / EVM 等指标热图。比如选择“白噪声 Es/N₀ × 衰减 dB”，或“多径路径参数 × 信噪比”。点击网格点恢复该点工程与基准种子，再进行单次运行。每个点使用相同的种子序列，便于比较。

## 📦 分包反馈与自适应速率

包级实验读取当前数字信源，按字节分包，添加包序号、长度和 CRC16，采用卷积编码与 AWGN 参考物理层。ARQ 根据 ACK / NACK 或超时重传；HARQ 累加多次接收的软信息，再进行 Viterbi 译码。界面展示包事件、反馈与超时、重传次数、完整交付比例、交付字节和 goodput。调节包长、重传上限、反馈丢失率与反馈时间，比较可靠性和完成时间。

AMC 实验设置信噪比起止值、帧数、反馈延迟和切换滞回。接收端从 64 个公共导频估计当前 Es/N₀，发送端依据到达的反馈，在 BPSK 1/2、QPSK 1/2、QPSK 3/4、16QAM 3/4、64QAM 3/4 之间切换。每帧实际进行编码、调制、噪声叠加、软译码和 CRC 检查，曲线同步显示档位、反馈估计、BER、FER 和 goodput。

## 🔬 算法过程、挑战与复现

算法演示区支持 Viterbi 网格与幸存路径、LDPC 校验和迭代、星座判决区域与 LLR；Huffman 过程来自当前链路的真实符号分布与编码树。逐步切换算法状态，并调整信噪比观察决策变化。

九项教学挑战覆盖可靠比特、清晰星座、包交付、自适应速率、图片像素恢复、音频 RMSE、RS 突发纠错、文件完整性和扩频抗干扰。每项挑战提供目标、操作步骤、示例入口和实测指标验收。实验差异对比同时列出工程参数变化和 BER、EVM、PAPR、吞吐率等指标变化。

导出 Python 实验会保存当前规范化链路、参数、种子及变量定义。将脚本放入部署包的 `工程文件/代码` 目录，运行 `.venv/Scripts/python.exe communication_experiment.py`（Linux 使用 `.venv/bin/python`），即可复现仿真，生成 `communication_experiment_result.json` 和海洋配色的 `communication_experiment_plot.svg`；图中同时展示信宿原始 / 接收波形和星座。工程完整 JSON 继续保存可恢复的链路和实验分析。
