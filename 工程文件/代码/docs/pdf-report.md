# 信号处理与分析 PDF 报告

v0.3.2 支持当前单实验报告，也可选择历史结果，将 1–50 组数据及图表合并为一个 PDF。报告不需要模型 API，生成新报告需要本地或部署的 Python 后端。

## 使用

1. 采集、导入信号或恢复已有实验，按需执行处理、方法比较和诊断。
2. 打开“模板与实验”，展开“PDF 分析报告”。填写标题、作者（可选）、分析目的（可选）和信号量纲；量纲默认 a.u.，只影响标注，不转换数据。
3. 选择标准版或简版，点击“预览摘要与章节”。核对摘要、章节与数据边界。
4. 点击“下载 PDF”。修改数据、恢复快照或改动报告设置后需重新预览。

标准版包括实验概览、波形与前后指标、FFT、Welch PSD、自相关、已有的方法比较与参数、已有的异常诊断、结论和复现信息；没有相应数据时省略章节。简版保留概览、关键指标、波形和可计算的频谱，常规输入约两页。未处理的数据也可生成报告，明确标注“尚未处理”。

## 选择最近处理结果

在“报告数据”选择“选择处理历史 / 已保存实验”。按波形缩略图、时间、方法和采样信息勾选结果，也可全选最近结果、清空或刷新。展开“补充选择已保存实验”可加入以前手动保存的快照；所有来源合计最多 50 组。选择“最近结果在前”或“按时间先后”，再预览、下载。

每个成功处理任务自动保留一组最终结果，同一任务的候选方法和内部处理步骤不会占据多组。普通问答、打开快照、失败和取消任务不新增记录；重试同一请求 ID 不重复记录，使用新请求重新处理相同输入则计作新的一次。历史按当前浏览器会话隔离，最近 50 组写入本地数据库，服务重启后仍可选。升级前没有留存的处理数据无法补回；已有手动快照可直接补充选择。更换浏览器或清除会话 ID 后不会自动显示原会话的记录。

合并报告有统一封面、汇总表、可点击目录和书签，随后分组展示图表与说明，页码连续。每组指标依据各自完整采样计算；不同输入、量纲或采样条件的指标不直接排名。报告量纲是全部所选组共同的显示标注，不转换数据；不同物理量应分开生成报告。50 组简版验收报告为 106 页，标准版会更长，具体页数取决于比较、诊断和说明内容。

存档不可变。盲测未揭晓时的记录不可选择；揭晓后新增可导出记录，也可重新保存实验快照。若所选历史滚出最近 50 次或快照被删除，刷新会移除该选择并提示重新预览，下载接口返回 409。滚出的历史不删除手动快照；失去全部引用的采样文件在“模型与设置 → 存储管理”预览确认后清理。

## 内容与排版

A4 白色页面，海蓝/紫色章节、鲸鱼封面、矢量图表、重复表头和页码；内嵌 Noto Sans SC 字体，中文可复制、搜索，离线 Windows/Linux/Docker 不依赖系统中文字体。超长文本自动换行与分页。字体未覆盖的装饰字符以 U+ 编码显示，避免缺字方框。作者留空时不显示作者栏。

说明直接依据当前采样、处理结果与真实指标生成。变差会写“下降”；无干净参考不计算真实 SNR/RMSE，不把幅值变小解释为去噪成功。常量、极短或时间间隔不一致的数据不输出缺乏依据的频域结论。诊断保持“特征提示”的解释，列出证据与其他可能原因。

指标使用全部采样点；显示曲线通过保留极值限制为最多 780 点。FFT 为去均值后 Hann 加窗的相对幅值；Welch 单边 PSD 使用最多 256 点、50% 重叠与窗能量归一化；自相关显示最多 48 个滞后。标准报告记录应用/算法/版式版本、参数及数据与结果 SHA-256。导出完整实验 ZIP 可保留全部采样；PDF 本身不替代实验数据包。

当前实验模式从会话锁下复制完整状态；历史模式在存储锁下读取所选存档，逐组计算后释放完整数组。内容 token 覆盖设置、样本、结果、章节及分组顺序；下载时重新核对。报告不读取模型 Key、聊天历史或服务器文件路径。盲测未揭晓时拒绝报告生成。当前不支持英语报告或模型润色。

## API

`POST /api/reports/preview`，Content-Type 为 application/json：

```json
{"session_id":"your-session","options":{"title":"信号实验报告","author":"","purpose":"","unit":"a.u.","edition":"standard"}}
```

不传 selection 时沿用当前实验模式，响应含 token、summary、sections、limitations 和前后指标。历史模式先调用 `GET /api/reports/history?session_id=your-session` 获取 history/snapshots 列表，然后向同一预览接口增加 selection：

```json
{"session_id":"your-session","options":{"edition":"brief"},"selection":[{"kind":"history","id":"结果ID"},{"kind":"snapshot","id":"快照ID"}]}
```

selection 长度为 1–50，不得重复，仅接受 kind/id；数组顺序即报告顺序。历史预览返回 group_count、token、options、summary、sections、limitations，不含整组绘图数组。缩略图接口为 `GET /api/reports/plot/{history|snapshot}/{id}?session_id=your-session`，返回 SVG 并检查会话及盲测状态。

将同样的 session_id/options/selection 与 token 提交至 `POST /api/reports/pdf`，得到 application/pdf。当前数据或设置变化、所选快照改名/删除或历史被淘汰返回 409；输入无效返回 400；两个渲染任务都被占用时返回 429。新增与选择无关的处理结果不会改变所选不可变历史的内容 token；页面数据刷新仍会要求重新预览。

配置在 `config/report.json`，各字段及日志见 [执行说明](exec.md)。单实验验收：`python scripts/test_pdf_report.py`；历史验收：`python scripts/test_report_history.py`，覆盖最近 50 次留存、重试、事务回滚、隔离、清理、盲测、独立指标、50 组图表/目录/书签/连续页码和实际 HTTP 下载。已发布的单实验示例在仓库根目录 [docs/report-example.pdf](../../../docs/report-example.pdf)。
