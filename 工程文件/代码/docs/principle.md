# 实现原理

## 模块框线与界面说明

`web/ocean.css` 用 `--module-border: 4px` 设置外层面板、导航边框，`--card-border: 2px` 设置内部卡片。外层 `--module-line` 与内层 `--card-line` 区分颜色层级。规则只作用于面板、卡片和图框，不改变 Canvas 曲线或输入控件的线宽；设置区域和报告选择卡片沿用现有 DOM 与事件。仓库根目录 `docs/showcase.css` 对静态演示采用相同边框参数。

页面文案精简集中在 HTML 和前端状态消息，数据校验和计算规则不变。PDF 预览通过原生 `details` 展开“数据说明”，后端返回的说明与 PDF 内容保持完整。当前数据的参考类型、评分条件以及模型 Key 保存与调用费用信息仍在相应操作处展示。界面验收日志为 `logs/ui-frames/browser.log`，服务输出为同目录 `server.log` 和 `server-error.log`；调试产物说明见 `debug/ui-frames/note.md`。

## 渐变、字体与回复排版

CSS 将青蓝、蓝紫、珊瑚粉线性渐变与局部径向光晕叠加，本地 `ocean-waves.svg` 提供半透明波纹，装饰不接收鼠标事件。`--ui-font` 先选 Times New Roman 的拉丁字符，再由 STZhongsong 提供中文，未安装时依次使用后备衬线字体。Canvas 绘制通过 `chartFont()` 与 `chartSurface()` 共用字体栈和图表背景色；不会改动曲线数据。日期时间由既有本地时钟每秒更新，CSS 将标识排在时钟下方。

`renderAssistantReply()` 仅识别已有的完整方法比较格式，从当前这条消息解析推荐方法和指标，并转义后展示标签/数值布局。全部原始回复放在原生 `details` 中；无法识别或尚未完成的文本继续进入原有 Markdown 渲染器。它不从当前工作区读取旧消息的指标，也不改变模型提示、信号计算、评分或 PDF 输出。重新渲染时按消息索引保留详情展开状态。

验收日志：`logs/ocean-visual/browser.log`，服务日志：同目录 `server.log`、`server-error.log`。调试说明、截图与隔离数据：`debug/ocean-visual/`。

## 从对话到工具

`server.py` 接收浏览器 HTTP 请求。`dialogue_agent.py` 按会话标识保存信号和对话状态，把“采集”“预处理”“分析”等意图转为函数调用。未配置模型时依靠关键词、数值提取和规则；配置模型后可用模型选择工具并组织解释。工具调用记录显示执行步骤。SSE 是一条持续返回事件的 HTTP 响应，前端逐步显示内容。状态存于内存，重启即丢失。

## 采集与随机性

`signal_processing.py`、`acquisition.py` 生成波形和噪声。采样率表示每秒样本数，时长与采样率共同决定样本数量。随机种子决定伪随机数序列；相同配置、种子和环境可以得到相同仿真样本。仿真保留干净信号作为参考；上传和麦克风没有真实干净参考，不能据此报告真实 SNR 提升。

CSV 单列按给定采样率生成时间轴，双列从相邻时间差的中位数估计采样率。数据应等间隔、数值有限；该加载器不是针对任意不规则采样的重建算法。“实时流”通道可由仿真产生，不代表实际硬件已连接。

加载器要求采样率为有限正数，双列时间严格递增且近似等间隔（时间间隔相对容差 0.1%，允许小幅导出舍入误差）。重复、倒序及明显不规则的时间轴会被拒绝，避免在不适用的时间轴上直接计算 FFT。

## 预处理与方法比较

滑动平均以相邻窗口的均值替代当前值，削弱快速变化，也可能抹平信号细节；中值滤波取窗口中位数，对孤立尖峰更稳健。鲁棒异常检测以中位数及绝对偏差估计异常，再抑制尖峰；去均值移除直流偏置。具体组合和参数在 `preprocessing.py`。

Agent 模式在 `dialogue_agent.py` 中生成候选方法和参数，结合平滑程度、相关性及有无参考等条件评分并选择。自动评分是课程演示启发式，不等价于所有任务下最优的滤波器。风险及控制建议由统计阈值生成，没有直接操控实际设备。

## 时域与频域

FFT 和 Welch 都先去均值。没有可用交流谱能量（谱功率和不超过 `1e-12`）时，谱熵约定为 0，FFT 不列出虚假的谱峰；这表示没有可归一化的谱分布，不代表恒定信号具有宽带噪声。

时域统计要求非空、有限的一维信号。只有一个采样值时没有相邻样本可用于统计过零，因此过零率约定为 0，避免对空差分求均值产生 NaN。

均值描述中心，方差描述波动，RMS 是平方均值再开方；自相关比较信号与延迟版本的相似性。频域分析通过离散傅里叶变换分解不同频率成分，功率谱衡量各频率贡献；主频取主要谱峰，谱质心和带宽描述频率分布位置及离散程度，谱熵描述归一化谱的分散程度。有限时长、采样率和窗函数影响估计，峰值不必等于真实系统唯一频率。

有干净参考时，SNR 以参考信号功率与误差功率之比取十进制对数并乘 10，单位 dB。演示固定 8 Hz 信号和 seed=42，用于核对完整流程。

## 随机过程扩展

`advanced_analysis.py` 的 AR（自回归）模型把当前样本写成若干过去样本的加权和，通过最小二乘法寻找使误差平方和最小的系数，再递推预测。AIC/BIC 把拟合误差与模型复杂度一起衡量；稳定性半径来自模型特征根。预测是模型假设下的短期外推。

Welch 功率谱把信号分成可重叠的小段，分别加窗并计算谱，再取平均，降低单次谱估计的波动。残差是实际值与 AR 预测之差，对残差的相关性检查帮助判断仍有多少结构未被模型解释。

Welch 返回实信号的单边功率谱密度（采样值平方/Hz）：负频率能量合并到正频率，除直流和偶数长度的 Nyquist 点外乘 2。把谱密度乘频率间隔后求和可检查交流功率；单位幅值纯正弦应约为 0.5。归一化使用采样率乘窗函数平方和，避免错误地少计算约一半能量。参见 [SciPy Welch 单边谱定义](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.welch.html)。

## 麦克风与报告

浏览器提交采样数组或编码 PCM16，后端识别噪声特征、实施频域噪声抑制并写 WAV；存在 FFmpeg 时可尝试转换 MP3，失败则保留 WAV。实际效果依赖录音环境。`run_demo.py` 通过编排器依次执行采集、处理、分析、决策，写出数据和报告，不依赖外部模型。

## 日志

发布脚本使用 Git 提交快照生成 ZIP，而不是遍历工作目录，避免把个人环境或运行数据打包。SHA-256 将 ZIP 的每个字节映射成校验摘要；下载后计算出的摘要一致，表示文件与发布产物一致。`RELEASE.json` 将版本与源码提交对应起来。

ZIP 条目按文件名排序，时间使用提交的 UTC 时间，权限与存储方式固定，避免构建时间、系统和压缩库版本改变包字节。调用 Git archive 时临时禁用自动 CRLF 转换并指定 LF，不改变使用者的 Git 配置。同一提交在 Windows/Linux 生成的 ZIP 可直接比较 SHA-256，确保发布文件与两平台验收的包一致。

Windows PowerShell 5 将重定向的原生 stderr 包装为错误对象，启动脚本在执行 Python 时允许记录这些文本，执行完成后检查退出码；警告不会中断服务，实际失败仍返回非零。Compose 的项目名限制为兼容字符，模板显式指定名称，避免从中文目录推导空名称。

发布验收从 ZIP 解压后建立全新虚拟环境，检查依赖和算法，再通过真实启动脚本运行服务，以 HTTP 请求验证页面、分析、流式回复、上传及合成音频下载。Docker 的健康检查定期请求 `/api/health`，但只证明服务可响应，因此还要执行功能验收。检查日志在 `logs/release/`、`logs/deployment/`，具体命令和配置见 [exec.md](exec.md)。

静态展示通过 `scripts/build_showcase.py` 对同一个 seed=42 的观测序列分别执行六种预处理，以已知干净参考计算每种方法的 SNR。图表的叠加曲线共享全局最小值和最大值形成的纵轴，保留幅值差异；显示曲线可降采样，数值指标始终由完整样本计算。上传观测 CSV 后没有干净参考，不能恢复这里的真实 SNR。

GitHub Pages 直接提供生成好的 HTML、SVG 和数据文件，不执行 Python，也不接收对话或分析任务。`logs/showcase/latest.log` 记录依赖版本、生成位置、样本数量、主频与 SNR 提升；`logs/regression/latest.log` 保存边界与统一纵轴回归检查。

`logs/server/server.log` 保存启动脚本输出，`logs/verification/latest.log` 保存集成检查结果，均覆盖写入。直接运行看终端；systemd/Docker 日志查看命令及全部参数见 [exec.md](exec.md)。输出数据、录音、上传文件和日志属于运行产物，不纳入仓库。

## v0.2.0：任务、快照与评分

FastAPI 负责请求校验和路由，Uvicorn 提供 HTTP/SSE。SSE 是一个持续输出文本事件的连接；此版本输出实际工具开始/结束、心跳与最终结果，断开连接不会取消后台任务。`request_id` 和参数摘要写入 SQLite，同一次重试读取原任务；不同内容复用同一 ID 会被拒绝。每个会话持有一把锁，避免同时修改其数组。有限线程池和队列控制同时执行的任务数。失败操作还原内存中的前一状态；进程突然退出时，恢复上一次成功保存状态，未完成任务标为失败而不重跑。单进程约束是锁生效的前提。

快照将 Python 数据类的普通字段编码为 JSON，把 NumPy 数组单独写入 NPZ，并用 SHA-256 检查数据完整性。NPZ 加载禁用 pickle，先检查解压规模、数组类型、维数及长度。SQLite 中的快照引用完整采样文件；绘图只使用它的显示副本，不会改变原始数据。ZIP 导入恢复结果和参数，不依赖再次请求外部模型；仅接受当前 schema 与算法版本。音频附件 URL 属于原服务，跨服务导入时清除这些链接，采样本身保留。

显示降采样把时间轴分为桶，保留每条曲线的桶内最小值/最大值，并合并为共同的、有序索引；这样短暂尖峰不会像固定步长抽样那样容易被跳过。HTML 报告使用同样方法，CSV 则输出全部采样。点数预算不足以同时保留所有曲线的所有极值时需增加预算，当前浏览器使用 520 点，足以分配现有的有限曲线数。

AR(1) 模板以 `x[t]=a*x[t-1]+sqrt(1-a²)*e[t]` 递推生成干净随机过程，再叠加观测噪声。`e` 为高斯创新，固定 seed+1；观测噪声使用 seed，两者不会复用同一随机流。正弦和脉冲干扰模板复用原生成器。

有参考时，评分为 RMSE 改善、与干净信号的相关系数、相对粗糙度误差三项加权和。RMSE 是逐点误差平方均值的平方根；粗糙度衡量相邻差分。抑噪/波形/瞬态目标的权重依次为 (65,25,10)、(45,45,10)、(35,25,40)，误差项取负。各项按 [-1,1] 或 [0,1] 截断，防止单位量纲或极端值主导排序。

无参考时无法知道真实误差或真实 SNR，评分只观察粗糙度下降、残差与输出的相关性、RMS 幅值变化；对应三目标权重为 (40,30,30)、(15,25,60)、(0,20,80)，瞬态目标另加最多 40 分的峰值变化惩罚。各项公开显示。平滑也可能抹掉真实细节，残差不相关也不保证信号正确，因此这些是启发式诊断，分数不能跨不同输入直接比较，也不应承诺某方法总是最好。评分不包含按方法名称添加的奖励。

参数搜索使用全量样本计算，只在候选参数数量超过预算时均匀选取有限候选；报告记录实际搜索数量和总耗时。540 例基准使用正弦、多频、扫频、脉冲和 AR 信号，记录 SNR/RMSE/相关、残差相关、幅值变化、谱熵和耗时。Welch 与 SciPy 对照时统一对称 Hann 窗、分段去均值、重叠取整和直流置零规则。浮点误差容差为 rtol=1e-10、atol=1e-12。

任务与实验数据存放在 `data/`，启动日志在 `logs/server/`，工作台/基准验证日志在 `logs/workbench/latest.log` 和 `logs/benchmark/latest.log`。错误任务通过 `/api/tasks/{id}` 可查询结果；队列满属于可用原 ID 重试的资源错误，不代表输入已被执行。

## v0.2.1：管理、兼容和进度修复

名称是快照元数据，重命名只更新清单，搜索在浏览器过滤列表；名称直接从原记录读取，避免用显示中的中间点拆分而截断。删除只移除同会话的命名快照，保留自动保存与共享采样文件，防止其他快照因文件被删而失效。没有引用计数或垃圾回收，因此删除不承诺立即释放存储。

应用版本表示产品发布；算法版本表示样本和结果解释契约。维护更新保持 schema 1 / algorithm 0.2.0，新增 app_version=0.2.1，旧清单缺少 app_version 仍可读取。不同算法版本继续拒绝导入。

进度缓存保留最近 256 个事件，以递增序号追踪读取位置。原来以数组下标追踪，缓存被截断后下标不再增长，导致新事件无法显示。现在读取序号大于上次游标的事件；缓慢订阅者可能跳过已淘汰历史，但仍看到最新进度与持久化最终结果。先读取完成状态，再读取事件，确保完成之前的最后工具事件被发送。

参数指纹忽略 respond_async，因为它仅决定返回方式、不改变计算；兼容旧版含 true/false 的摘要。服务端最后写入内部 operation 字段，客户端无法把不同操作伪装成同一任务。当前数据模式不会提交生成参数，选择新模板才重新生成数据。日志位置和覆盖规则保持不变。

## v0.2.5：导入、对比与生命周期

导入模块按 CSV 规则或空白分隔读取文本，保留每条记录的文件行号；仅将所选列转为浮点数。毫秒/微秒/纳秒乘以相应系数转成秒；时间必须递增且近似等间隔，再以间隔中位数的倒数推断采样率。没有时间列时生成 t[i]=i/fs。错误记录不会被静默跳过。预览 token 是文件 SHA-256 与规范化选列设置的摘要，确认时重新解析并验证，避免选择改变后导入旧预览。记录文件名、文件摘要和映射供复现。

对比读取快照，不改变当前会话。输入身份由完整时间、观测、采样率和参考标志构成，有干净参考时也包含参考数组。只有身份、目标、评分版本全部一致且都有评分才并列比较得分。无参考不计算真实 SNR/RMSE。有参考时 RMSE 为逐点误差平方均值的平方根，SNR 为参考功率与误差功率比的 10 倍常用对数；误差功率不大于 1e-12 且参考功率为正时，以 99 dB 作为约定显示值，零参考功率时不报告 SNR。叠加图使用统一横纵轴；频谱先去均值、乘 Hann 窗、FFT 后取幅值并除以样本数，用于相对观察，不标作校准功率谱。显示曲线保留极值，指标用完整数据计算。

调度器限制活动任务总数，每个会话一次只派发一个任务，空闲线程可处理其他会话。待派发任务可立即取消并释放容量；已派发任务使用线程事件，在工具调用/参数候选边界检查。取消异常直接交给任务引擎，避开工具的常规错误回退；恢复任务开始前的内存状态，不写入新的自动保存。保存边界之后拒绝取消，避免界面显示取消而实际上已提交结果。任务终态持久化，旧 ID 不会重新执行。进程意外中断仍恢复最近成功自动保存。

每个访问或排队任务为会话增加使用计数，计数大于零时不可释放。维护线程清除超时且无使用者的会话；容量不足时先移除最久未使用的空闲会话。只清内存，磁盘自动保存保留，下一次访问重新读取。

清理器扫描严格符合内容寻址文件名的 NPZ，排除符号链接，读取所有快照的引用集合，计算无引用文件及大小。预览 token 包含候选文件名、大小与修改时间；确认时在与保存/加载相同的文件锁下重新计算，变化即拒绝。删除前确认解析后的路径仍在数据目录内。此锁是单进程锁，因此同一个数据目录仍只支持一个后端进程。数据库、原始上传、音频和不符合命名规则的文件不在清理范围。

新增任务 operation 列保存可读操作名，启动时自动迁移旧数据库并保留已有结果。快照 schema/算法版本未改变；应用回退应恢复升级前数据库备份。日志仍覆盖写入，新增验证日志为 logs/studio/latest.log。


## v0.2.6 时频证据、盲测与验证

STFT 把信号切成带重叠的短片段，每段乘 Hann 窗后作实数 FFT。单边功率密度为 |FFT|²/(fs×窗平方和)，内部频点乘 2；频率间隔 fs/窗长，时间步长 hop/fs。窗越长频率越细但时间越模糊，频率间隔不是故障定位精度。短信号降至可容纳的 2 次幂窗并明确报告；首尾补零、半窗区域可能有伪影。显示相对所选区间最大 PSD 的 −80 至 0 dB，跨区间颜色不可直接当作绝对幅值比较。超出 240×128 格用最大值聚合保留强瞬态，检测仍使用完整样本/帧。

脉冲用二阶差分超过 max(8×MAD,1.5×全段 RMS)；归零用近零连续段；削顶用较大非零连续平台；漂移用帧均值偏离中位数；窄带用逐频点中位功率基线及功率占比；主频改变用每帧最高非直流功率与最初四分之一帧基频比较。正常方波、调频、静音、有效载波可能触发，卡片展示替代解释。检测不读取注入真值、干净参考或脉冲掩码；未检测到不代表没有故障。

注入由固定 NumPy 随机种子决定相位/脉冲位置，基线与参考在内部保存。盲测揭晓前无真值/种子/参考误差输出；揭晓重新对全段观测检测，按类型匹配区间交并比 IoU≥0.2，一个检测/真值最多匹配一次。脉冲真值前后扩展 max(1/fs,0.02 秒) 容忍差分边沿偏移。precision=匹配/检测，recall=匹配/真值，F1 是二者调和平均；空分母记 0。间隔重叠或时频扩散可能导致误报与漏检，评分不会修饰成完美结果。

验证仅修改事件区间：局部 FFT 陷波移除卡片频率邻域；中值压制尖峰；线性去趋势去除基线；削顶/归零用两侧端点插值（无法恢复真实高频细节）。陷波/去趋势两端混合减少接缝。区间外逐点保留；有参考时显示区间 RMSE，否则只显示 RMS、变化和频带能量，不声称恢复真实信号。频率变化无自动滤除建议。

输入、参数、处理样本哈希生成 token；验证和采用均重新检查，防止旧卡片处理新数据。采用仅更新 processed，观测与真值不变。新字段进入原有非 pickle JSON/NPZ 快照，数组长度校验与旧字段默认值保持 schema 1 兼容；诊断配置独立版本 1.0，六方法算法契约仍为 0.2.0。STFT 分块与注入/显示聚合有协作取消检查点；取消由任务引擎回滚当前状态。

诊断验收日志 `logs/diagnostics/latest.log`、发布测试 `logs/release/latest.log`、部署 `logs/deployment/latest.log`、浏览器 `logs/browser/latest.log` 均覆盖写入。调试截图位于 debug/v026，仅用于此次验证。

## PDF 报告的数值与排版（v0.3.1）

报告先在会话锁内复制当前状态，再释放锁计算，避免读取到一半更新的数据。只选择信号、配置、结果和允许的滤波参数。完整时间/观测/参考/结果按小端 float64 输入 SHA-256 得到数据标识；再对这些事实、设置与版式版本的有序 JSON 求哈希作为预览 token。下载重新计算并比较 token，过期返回 409。它是内容一致性检查，不是账户认证。

RMS 是平方平均后开方；标准差移除均值，峰峰值是最大减最小；相邻变化量是相邻样本差值的 RMS。有干净参考时 RMSE 衡量结果与参考的平方平均误差，SNR=10log10(参考功率/误差功率)。参考功率近零不算 SNR，误差不超过 1e-12 约定上限 99 dB 并在报告说明。频谱主峰来自去均值/Hann 窗；时间间隔不符合采样率则跳过频域，交流谱不足不输出主频。无参考只描述观测变化。

绘图采用保留极值的共同索引，最多 780 点，不用显示采样替代全部指标计算。ReportLab 用矢量线和矩形生成科学曲线与时频图；Flowable 必须在实例中预留尺寸，KeepTogether 让标题和图保持连续。文字使用 CJK 换行和嵌入 TrueType 子集，Noto Sans SC 由官方可变字体实例化为常规字重，许可证见 assets/fonts/OFL.txt。模型服务不参与报告生成。

两个渲染许可限制并发占用，结束或失败都会释放；页数上限和输入长度限制控制排版。正文不含 Key、聊天或路径；报告预览只返回摘要、章节、指标与 token，不包含全部绘图数组。盲测先揭晓才能生成完整 PDF。

验收日志 logs/pdf-report/latest.log 与 browser.log 覆盖写入；debug/pdf-report 中保留逐页渲染检查。发布验收 logs/release/latest.log 记录干净安装、全部 104 项测试与 540 个基准案例；部署冒烟 logs/deployment/latest.log 增加 pdf_report 检查。

## 不可变历史与多组报告

一次成功任务产生新的处理结果后，任务引擎复制报告所需字段到独立 ConversationState，只保留采样、处理结果、比较和诊断证据，不复制聊天、Key 或上传路径。来源转换为有限类别，仿真依据生成器的 waveform+noise_model 标记识别。压缩数组按 SHA-256 文件名写入 NPZ，数据库存储 JSON 元数据和文件引用；相同数组可共享文件，不使用 pickle。

自动保存、插入历史、按时间淘汰第 51 组及任务成功状态使用同一 SQLite 事务，ContextVar 让该线程中的嵌套存储调用复用连接。任一写入失败则整个数据库事务回滚，任务引擎恢复之前的内存状态。文件先原子替换再提交引用；失败留下的无引用文件由常规预览确认清理。所有写入、报告读取及文件清理共用存储锁，防止报告读取时文件被回收。淘汰历史不会淘汰手动快照，清理查询两类引用。

存档按 session_id 查询，只保留最近 50 次成功处理任务；候选方法不是额外一次处理。任务 ID 去重，打开/导入快照等非处理操作排除，处理对象未变的普通问答也排除。揭晓后可新增包含已揭晓状态的记录，之前的盲测存档保持不可变和禁用，避免利用历史导出绕过盲测。会话 ID 是既有浏览器数据隔离机制，不替代部署认证。

selection 按用户顺序携带 history/snapshot 和 ID，服务逐组恢复完整数组、计算完整指标及有限图表，然后释放该组数组，只累积事实与最多 780 点曲线。内容 token 覆盖所选记录元数据、事实、顺序和全局设置。下载再次计算；删除、淘汰、快照改名或设置变化会拒绝旧 token，新增无关任务不改变不可变记录。读取缺失组时明确失败，不静默跳过。

ReportLab 将各组正文组成一个文档，共享中文字体子集；多次排版收集章节页号，生成 PDF 书签及目录链接，所有页使用同一页码计数。标准版复用各组现有比较/诊断/复现章节，简版复用波形与频谱，不用页面截图替代科学图表。输出只汇总各自指标，不将不同输入按 SNR/RMSE 排名。单实验上限 24 页，合并上限 1208 页，仍限制两个同时渲染任务。

历史验收及浏览器日志分别覆盖写入 logs/report-history/latest.log、browser.log；最大输入计时在 maximum-input.json。部署冒烟日志 logs/deployment/latest.log 增加 report_history 与重启持久化检查。独立调试脚本、数据及逐页图片在 debug/report-history/，不进入部署包。

## 通信积木编译与仿真

v0.4.1 发布汇总本节全部通信扩展。应用版本 0.4.1 与实验 schema 1、信号处理 algorithm 0.2.0 分开管理，升级不会使已有实验数组失效。部署包只从已提交 Git 快照生成，固定 ZIP 顺序、时间和权限，并在 RELEASE.json 中绑定提交；SHA-256 绑定验证结果与实际上传字节。发布验证在新虚拟环境执行全套测试，GitHub 的六组平台/Python 验证与 Docker 重启检查记录在 Release 的 verification.json。构建、干净部署、CI 与发布核验日志覆盖 `logs/release/`。

自动接收功能由 `receiver_recovery.py` 实现：非线性谐波估计初相，绝对值早迟门或 Gardner 误差驱动 PI 跟踪；同步输入仅为接收波形和公共帧参数。DFE 用前向滤波和过去硬判决抵消后游串扰；固定结构从配置响应设计，自适应结构根据实际发送的公共前导训练，并可转为判决引导更新。LMS 沿平方误差梯度更新，NLMS 按输入能量调整步长，RLS 递推更新逆相关矩阵；三者均不读取干净数据。数学公式、参数含义、前导帧格式、误差传播与有限帧限制见 [同步与均衡](receiver-recovery.md)。本次 22 个旧示例逐字段对照在 `logs/communications-recovery/compatibility.log`，算法观测在 `probe.log`，页面及三宽度检查在 `browser.log`，文档链接检查在 `docs.log`；这些日志覆盖写入。课件页图、隔离服务数据和截图在 `debug/communications-recovery/`。

第四章扩展在 `src/baseband.py` 实现独立实波形分支，包含线路码、成形脉冲、采样信道和接收。Build 对“比特→线路电平→基带波形→线路电平→比特”执行类型与配对检查，把电平展开、过采样、保护区和滤波尾计入资源限制；该分支不将三值线路电平当成二进制比特。原复符号和模拟复包络分支保持原输出。完整公式和参数见 [线路编码与基带原理](baseband-coding.md)。

线路编码以电平和跳变承载比特：差分比较相邻电平，AMI 交替传号，Manchester/Miller/CMI 规定半位跳变，HDBn 用可识别的同极性传号替代长零串。发送器先每 sps 点放一个电平，再与脉冲卷积。fs=Rs×sps；匹配接收将发送脉冲反向并按能量归一化，按已知帧起点和滤波延迟抽样。RC 满足理想 Nyquist 零串扰采样条件；RRC 要与匹配接收联合考虑，有限截断仍会残留误差。手动抽样偏移不等价于自动时钟恢复。

实白噪声方差按发送有效数据段均方功率和采样 SNR 定义，带限 AWGN 再将信号与噪声共同限制在 ±W；不能直接套用旧复符号 Es/N0。FIR 信道用可配置前后游抽头形成串扰，频域信道在带零保护区的有限周期帧上滤波。ZF 解中心 2N+1 个采样点的逆响应方程，外围仍有残余 ISI；正则 MMSE 用误差与系数能量的权衡减少病态逆响应。响应来自配置的单位脉冲传播，未用干净消息估计，随机丢失不能被固定均衡逆转。

实基带波形、频谱及眼图取自计算数组。双边周期图积分对应含零保护区的全帧功率，噪声参考另用有效发送段功率；眼图是定时/均衡前接收滤波输出的两码元真实切片。完整判决电平、误码率和均衡前后 RMSE 用数据段统计。课件例题、噪声方差及采样率、RRC 级联、频率响应、有限 ZF 残余量均有独立数值断言。日志分别为 `logs/communications/latest.log`（当前 49 项）、`logs/communications-coding/compatibility.log`（第四章初次扩展的十个旧示例对照）、同目录浏览器与服务日志；真实 HTTP 冒烟在 `logs/deployment/latest.log`，临时课件页图、脚本及隔离数据在 `debug/communications-coding/`。自动同步、DFE 及自适应训练后续已补充，原理及新增日志见 [同步与均衡](receiver-recovery.md)。

积木箱将发送端划分为发转换器与调制器，将接收端划分为解调器与收转换器。发转换器处理模拟样本或比特的编码/交织，调制器将比特映射成复基带符号；解调器对复符号判决，收转换器执行逆序解交织/译码并按需恢复模拟样本。分类元数据用于积木筛选和颜色；编译与数值算法仍按积木 kind 和参数执行，工程内不保存分类，因此旧 JSON、浏览器草稿及 Build token 不因分类变化而改变。

分类细分的兼容对照结果覆盖写入 `logs/communications-categories/compatibility.log`，列出旧数字/模拟/文字示例在修改前后的工程、Build token 和完整输出对照；`browser.log` 保存六类积木名称、布局测量与实际运行检查，隔离服务输出为同目录的 `server.log` / `server-error.log`。

工程是带唯一标识和类型参数的有序积木列表，不包含可执行代码。草稿校验保留未完成数值，Build 再执行严格范围和完整链路校验。编译器从模拟样本/比特开始沿列表传播类型和数量，遇到调制转为复符号，解调回到比特，PCM 译码回到模拟样本。编码器入栈，接收端按相反顺序弹栈并检查参数，提前计算重复、码字填充、交织填充、卷积尾位和调制分组长度，避免在无效链路上分配大数组。

规范化工程的有序 JSON 经 SHA-256 生成 token。Run 重新 Build 并核对 token，确保结果对应已构建配置；没有服务器编译缓存或用户代码求值。参数编辑立即取消前端构建和结果。每次运行以 SeedSequence 派生独立信源与噪声随机流，相同种子与完整配置复现相同输出，显示雪花的随机数不参与仿真。

PCM 把 ±量程划分为 2^b 个含端点的均匀重建电平，取最近电平并饱和，再按高位在前输出 b 位。重复码按奇数个硬位多数判决。Hamming 将数据置于 3/5/6/7 位，1/2/4 位为偶校验；三位综合征指出要翻转的位，多位错误可能误纠正。卷积码状态是前两位，两个输出分别为当前位 XOR 前两位及当前位 XOR 前第二位，零尾使最终状态回零；Viterbi 以汉明距离逐级选择四个状态的最短路径，再从零状态回溯整帧。交织将补齐矩阵按列读出，接收端逆变换；解码后逐层移除编译时记录的填充。

BPSK 采用 ±1，QPSK 为 (±1 ±j)/sqrt(2)，16-QAM 每轴用 Gray 标记的四级 ±1/±3，再除以 sqrt(10)。接收端以欧氏距离选择最近码本点。AWGN 的 I/Q 方差分别为 N0/2，N0 以标称发送 Es=1 计算，故前置衰减会降低实际接收 SNR。各信道按配置顺序作用于复样本，理想已知补偿只除以累计复增益。准确公式、指标分母、显示抽样与当前物理模型范围见 [通信指南](communications-lab.md)。

全部 BER/EVM/RMSE 使用完整帧；信宿返回完整数组，画布分窗口浏览；信道和星座仅返回有限前缀用于绘图。数值有限性在导出前检查。线程池执行计算，有界信号量限制同时运行数，finally 释放许可；服务状态与原工作台/报告历史隔离。

日志：`logs/communications/latest.log` 为当前 49 项数值/API 验收，`browser.log` 为原始真实浏览器操作与各宽度检查，隔离服务日志在同目录；`logs/deployment/latest.log` 记录包括通信链路在内的真实 HTTP 冒烟。均同名覆盖。`debug/communications/` 只存测试工程、隔离数据、脚本及截图，不参与产品交付。

### 直接模拟调制分支

模拟信源还可以不经过 PCM，直接通过 AM/DSB-SC/SSB/VSB/FM/PM。编译器增加“模拟复包络”类型，按模拟采样时钟传播；FM/PM 包含一个已知零相位训练样本，解调后去除。Build 拒绝模拟/数字调制或噪声混用、制式不配对、边带/低通超 Nyquist 和相邻相位变化达到 π 的工程；数字分支和旧固定种子输出保持一致。

复包络把射频载波的快速振荡提出来，只计算承载信息的 I/Q。AM/DSB 改变实部，SSB 用 Hilbert 相移或单侧频谱滤波，VSB 用相对载频互补的过渡响应；FM 把信源积分为相位，PM 直接把信源映射成相位。AM 包络检波在包络翻转时产生失真，相干检波保留正负信息。FM 的相位差分恢复频偏，PM 的展开相位扣除已知初相后恢复信源；未借助干净信源来解调。详细公式、FFT 周期边界、参数单位、六种方法的课件页码和模型边界见 [模拟调制原理](analog-modulation.md)。

模拟噪声按照完整发送复包络的实测功率计算，I/Q 各有一半噪声方差。指标使用完整还原帧，包括 RMSE、最大误差、输出信误比和归一化复包络误差；模拟链路不计算 BER/码率/星座。发送频谱为双边周期图，除以 fs·N，以 dB/Hz 显示并对零功率设置有限显示下限；它是相对载频的频谱，没有伪造射频采样。浏览器和隔离服务日志在 `logs/communications-analog/`，PDF 提取、临时脚本和截图在 `debug/communications-analog/`。

## v0.4.7 业务传输与教学实验增强

业务信源将文件和灰度像素转换为 MSB 优先比特序列，将音频转换为归一化单声道 PCM 样本。信宿按原始媒体结构重建内容，逐字节计算 SHA256、均方误差与峰值信噪比，音频统计完整采样帧的 RMSE 与信误比。Huffman 依据实际字节频率生成规范前缀码，码长表和原长度随帧传输；ADPCM 根据预测残差的 4 位码字递推量化步长。BCH (15,7) 在 GF(16) 上纠正两位错误，RS (255,223) 在 GF(256) 上纠正 16 个错误字节，交织将连续受扰字节分散到不同码字。详细参数与实现入口见 [v0.4.7 指南](communications-v047.md)。

DSSS 把一个单位能量符号分配到 L 个正负 PN 码片，使用 1/√L 缩放保持总能量，码片率随 L 增加。接收器从公共训练扫描码相位与延迟，相关解扩累加同一码序列上的信号；RAKE 先估计多径延迟与复增益，再按共轭增益合并各指输出。SIMO 选择合并使用最强接收支路，MRC 以信道共轭加权；Alamouti 利用两天线、两时隙的正交结构恢复符号；2×2 空间复用以 ZF 或 MMSE 矩阵解开两路数据。公共训练支持接收端信道估计，完整阵列结果用于核查能量、时隙和检测性能。

工程变量保存于 schema 2 文档的 `learning.variables/bindings`。数值求解器读取算式 AST，允许常量、已定义变量、括号和算术运算；依赖关系递归求值，循环依赖直接报错。一次求值将绑定写入 schema 1 工程的具体数值参数，再交给原 Build 规范化与生成 token。原始公式留在工程文档，构建与运行使用求值后的确定数值。

二维扫描由两组具体参数值组成笛卡尔网格。每个点使用相同的 `seed + 帧序号` 序列，按真实仿真累计错误比特、符号、帧数与 RMSE/EVM 等量；BER、SER、FER 采用累计分母，区间采用 Wilson 公式。每点保存完整数值工程和基准种子，点击热图后可复现该点。Es/N₀ 扫描同时更新对应软解调噪声方差，使恢复的工程与扫描计算一致。

独立分包积木使用 16 位包序号、16 位有效字节长度、有效数据和 CRC16。包级控制器以同一格式承载当前数字信源，经过 (7,5)₈ 卷积半码率、BPSK/QPSK、AWGN 和软 Viterbi。ARQ 每次对新收到的 LLR 独立译码；Chase HARQ 对相同码字累加各次 LLR，再重新译码。接收成功由 CRC 和包序号判定；丢失的反馈触发超时，重复包按序号去重。发送时长由实际码元数除以码元率得到，反馈与超时加入时间线；goodput 为实际交付信息比特除以全部耗时。

AMC 从每帧 64 个已知导频的接收残差估计 Es/N₀。反馈在下一帧加上配置的额外延迟后可用，发送器按门限和滞回选择 BPSK 1/2、QPSK 1/2、QPSK 3/4、16QAM 3/4 或 64QAM 3/4。3/4 码率通过卷积码打孔实现，接收端在删除位置放入 LLR=0，再执行软 Viterbi。每帧实际执行调制、噪声、检测、译码和 CRC，统计档位切换、FER、BER 与含导频开销的有效吞吐率。

算法演示来自逐步计算数据：Viterbi 显示各状态累计代价、幸存前驱和回溯路径；LDPC 显示逐轮校验综合征与信息位错误；星座图按欧氏距离划分判决区域并展示 Max-log LLR；Huffman 树使用当前运行的实际码表。挑战将本次结果的指标与目标阈值逐项比较，媒体目标可以使用 `sink.media.metrics` 下的误差或完整性指标。工程比较按积木 ID 对齐参数，列出位置、类型、数值变化和实测指标差值。

导出 Python 脚本内嵌规范化工程、随机种子及公式元数据，调用与页面相同的 Build / Run 接口，写出完整 JSON；标准库生成独立 SVG，绘制同一结果中的信宿波形与星座。工程快照保存教学笔记、基线、变量、二维结果与反馈实验。验证日志覆盖 `logs/communications-v047/`，发布环境验证覆盖 `logs/release/`；调试材料及最近文档备份位于 `debug/v047/`。

## v0.4.8 闭环与空间通信

闭环控制器将包头、载荷和 CRC 送入当前工程，保留用户的编码、信道和接收结构。ARQ 使用当次判决，Chase HARQ 在对应判决点累计软值；捕获状态、CRC 和序号共同决定 ACK。实际天线能量、发射样本长度与采样率用于统计空口耗时及吞吐。AMC 从实际接收训练估计质量，按延迟到达的反馈选择调制档位。子工程实例使用独立积木 ID 保存状态，公开参数映射至具体字段，版本定义与实例值分别保存。见 [闭环与子工程原理](communications-v048-closedloop.md)。

空间通信采用 2×2 复矩阵模型。SIC 按检测后质量选择空间层，判决后重构并相减；动态信道将 Clarke/Jakes 时变衰落与收发相关矩阵组合，公共导频估计并插值 H(t)。MIMO-OFDM 逐子载波估计矩阵，OFDMA 保存独立用户队列、信道与接收统计；FHSS 使用公开跳频序列捕获码相位、帧延迟并解跳。完整天线数组用于图表和能量统计。见 [无线算法原理](communications-v048-wireless.md)。

I/Q 回放由文件给出实际采样率、复样本和公开帧格式，接入现有接收积木；报告接收样本、比特与功率，导出的 SigMF 保存样本格式和接收配置。任务验收逐种子重跑实际链路；批量实验累积错误与比特数计算 BER，目标搜索完整测量配置网格并选择满足阈值的最低点。见 [任务与统计原理](communications-v048-experiments.md)。

## 🌊 v0.4.10 自主接收与实验分析原理

MLSE 把最近 L−1 个符号作为状态，使用公开训练估计复 FIR，再对每条候选转移累积接收样本的欧氏距离，回溯得到整段符号序列。MUSIC 从接收协方差的特征向量中建立噪声子空间，扫描阵列响应与该子空间的正交程度；公开导频选择目标峰，MVDR 再依据训练残差协方差形成接收权重。TDL 使用 3GPP A/B/C 的标准功率时延表，按 RMS 时延扩展缩放，并用分数延迟 FIR 和逐路径 Jakes 相位实现连续衰落。[详细数值与来源](communications-v0410-receiver.md)。

自描述物理帧把载荷长度、MCS、包序号、业务偏移和总长度放入 CRC16 与卷积码保护的 BPSK 帧头。接收先相关捕获前导，再软解帧头并按实际字段接收载荷；成功包写入对应业务位置并记录覆盖区间。Turbo 由两个公开交织连接的 RSC 编码器组成，两个 BCJR 译码器反复交换“后验减去信道信息与先验”的外信息。IR-HARQ 发送不同 RV 选择的卷积母码位，把各轮实际 LLR 按母码位置累加，再执行 Viterbi 和 CRC；Chase 对照重复同一 RV，并采用相同每轮编码预算。[帧格式、公式和接口](communications-v0410-framing.md)。

本次算法回放按积木 ID 保存真实输入、输出与内部步骤；测量诊断从观察点计算规则结果，逐块耗时由运行观察器计时。约束选参完整测量两参数候选网格，以配对种子比较并计算可行 Pareto 集；教师评阅读取每个阶段独立快照，按原验收种子重跑。帧级场景按 step/linear 时间表修改信道参数，保留状态并记录连续达标的恢复时间。[统计和教学实现](communications-v0410-experiments.md)。

两路汇合先缓存共享发送与信道输出，两条接收分支使用同一份实际采样，在相同类型、长度和采样率的复符号或 LLR 端口处加权或选择，再运行共同的后续解调译码。OFDM 单目标通感把回波延迟映射到距离、把慢时间相位变化映射到速度；通信端用公开训练均衡，本机雷达用本地发射网格与接收网格之比形成二维延迟—多普勒谱，展示实际谱峰和分辨率。

主题子页复用已有 DOM 控件和处理器，工程保存记录实验表单、结果、教师评语和场景。验收日志位于 `logs/communications-v0410/`，图表与浏览器调试材料位于 `debug/v0410/`，完整功能入口见 [v0.4.10 指南](communications-v0410.md)。
