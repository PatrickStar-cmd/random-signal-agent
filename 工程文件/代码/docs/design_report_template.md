# 随机信号智能体设计报告

## 1. 项目背景

随机信号课程强调随机过程建模、统计特征估计、相关分析和频谱分析。本项目将这些知识点封装为一个可运行智能体系统，使智能体能够从模拟传感器连续采集信号，自动完成噪声预处理、时频域特征分析和控制决策。

## 2. 需求分析

项目任务要求以智能体为核心载体，将课程知识点与智能体感知、决策、控制流程深度融合，实现随机信号实时采集、噪声预处理、时域与频域特征分析等功能，并提交设计报告、项目演示和 PPT 汇报。

本项目对应实现如下：

- 实时采集：`SensorAgent` 逐窗口产生带噪随机信号。
- 噪声预处理：`PreprocessAgent` 完成异常点抑制、去均值和滑动均值滤波。
- 时域分析：`FeatureAgent` 计算均值、方差、RMS、峰峰值、自相关等指标。
- 频域分析：`FeatureAgent` 基于 FFT 估计功率谱、主频、谱质心、带宽和谱熵。
- 决策控制：`DecisionAgent` 根据 SNR、谱熵和异常点比例给出控制动作。

## 3. 总体架构

系统采用多智能体流水线：

```text
随机信号源 -> SensorAgent -> PreprocessAgent -> FeatureAgent -> DecisionAgent -> 报告/演示输出
```

这种结构参考了《从零开始构建智能体》中“任务拆分、专职智能体协作、统一编排输出”的项目组织方式。与通用 LLM 智能体不同，本项目的智能体以课程算法为工具，不依赖外部 API，便于课堂演示和复现实验。

## 4. 算法设计

### 4.1 信号模型

仿真信号由确定性周期分量、低频趋势、AR(1) 随机扰动、白噪声和少量脉冲干扰组成：

```text
x(t) = A sin(2*pi*f*t) + trend(t) + ar(t) + n(t) + impulse(t)
```

其中 AR(1) 分量用于体现随机过程的时间相关性，白噪声和脉冲干扰用于模拟实际采集中的观测噪声。

### 4.2 噪声预处理

预处理流程包含：

- 中位数绝对偏差 MAD 检测脉冲异常点。
- 用局部中位数替换异常点。
- 去均值降低直流分量影响。
- 滑动平均抑制高频白噪声。

### 4.3 时域特征

提取均值、方差、标准差、RMS、峰峰值、零交叉率、偏度、峰度和一阶自相关系数。这些特征可反映随机信号的能量、波动强度、分布形状和时间依赖性。

### 4.4 频域特征

采用 rFFT 得到单边频谱，并由功率谱估计主频、谱质心、谱带宽和谱熵。谱熵越大表示频谱越分散，信号越接近宽带噪声。

### 4.5 决策控制

决策智能体根据特征规则输出控制建议：

- SNR 低：提高滤波窗口、延长采样时间。
- 脉冲异常点多：启用鲁棒异常点抑制。
- 谱熵高：判定宽带噪声占优，提示检查传感器和采集环境。
- 主频明确且 SNR 良好：判定信号稳定，可降低滤波强度以保留细节。

## 5. 实验结果

运行 `python run_demo.py` 后，系统会在 `outputs/` 下生成结构化结果、CSV 数据、HTML 演示页面、Markdown 设计报告和 PPTX 汇报文件。演示页面包含原始信号、预处理信号、功率谱和智能体决策摘要。

## 6. 创新点

- 将随机信号课程算法封装为可解释的智能体工具链。
- 不依赖云端模型，能够离线复现实验。
- 将感知、预处理、特征分析和决策控制统一到一个自动化闭环中。
- 自动生成报告和 PPT，便于课程汇报。

## 7. 结论

本项目完成了随机信号智能体的基础闭环：从信号采集到噪声处理，再到时频域特征分析和控制决策。它既能作为课堂项目演示，也可作为后续接入真实传感器或大模型解释模块的基础框架。
