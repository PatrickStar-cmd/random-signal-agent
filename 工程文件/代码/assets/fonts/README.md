# Report font

`NotoSansSC-Regular.ttf` is a static weight-400 instance of Google's Noto Sans SC TrueType variable font. Source: <https://github.com/google/fonts/tree/main/ofl/notosanssc>. The upstream file was downloaded on 2026-10-08 and instantiated with fontTools 4.66.1; fontTools is an authoring tool and is not a runtime dependency.

The font is redistributed under the included SIL Open Font License 1.1 (`OFL.txt`). ReportLab subsets and embeds used glyphs in each PDF. The full Chinese font ships with the application so offline Windows/Linux/Docker deployments do not depend on system fonts. Unsupported decorative characters are written as `U+...` labels rather than missing-glyph squares.
